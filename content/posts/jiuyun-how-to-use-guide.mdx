## 九云 机场简介与使用前须知

在开始具体的使用教程之前，我们先来简单回顾一下**九云**这家机场的核心特点。作为一家主打高性价比和稳定解锁的节点服务商，九云 在众多平价机场中拥有相当不错的口碑。如果你想了解它的具体测速数据和历史稳定性，可以先阅读我们的 [九云 评测与测速数据](/airport-observation/jiuyun-airport-comprehensive-review-and-streaming-guide) 以及 [九云 品牌介绍与最新优惠](/brands/jiuyun)。

### 九云 的核心优势
- **网络带宽**：采用海外中转架构，主打低延迟连接，应对日常网页浏览和视频流媒体绰绰有余。
- **解锁能力**：流媒体和 AI 工具爱好者福音，完美支持 Netflix、ChatGPT、TikTok 等主流受限服务。
- **设备并发**：支持 3-5 台设备同时在线，满足手机、电脑、平板等多终端同时使用的需求，也适合家庭小规模共享。
- **路由策略**：智能路由自动择优，不论你在哪个运营商网络下，都能自动匹配最顺滑的线路。
- **客服支持**：提供专业客服，快速响应用户的工单反馈。
- **流量规则**：需要注意的是，**常规套餐默认每月订单日重置流量**，当月未用完的流量不会累积到下个月，因此在选择套餐时需要根据实际需求合理预估。

## 九云 套餐怎么选？(基于真实价格分析)

很多新手在注册 九云 后，面对多种套餐常常不知道该如何选择。九云 的定价策略非常亲民，起步价极低，同时提供了一次性（按量计费）套餐，灵活性很高。

### 1. 轻度用户或备用机场首选（约 ¥6/月 起）
九云 提供了极具性价比的入门级常规套餐，最低仅需约 6 元 / 月。
- **适用人群**：平时仅需要查阅技术文档、偶尔使用 ChatGPT 提问、刷刷推文，或者已经有一个主力机场，只需要一个高性价比的备用机场的用户。
- **购买建议**：由于常规套餐流量在**每月订单日重置**，且未用完的流量不结转，对于轻度用户而言，6元档的流量通常足够使用。建议按季或按半年订阅，既能享受优惠，又不用担心投入太多。

### 2. 视频流媒体重度用户（进阶常规套餐）
如果你是 Netflix、YouTube 4K 视频的重度依赖者，经常刷 TikTok 短视频，那么入门级的流量可能不够你折腾。
- **适用人群**：经常看海外流媒体、经常下载海外大文件、或者家里有 3-5 台设备同时连外网的用户。
- **购买建议**：建议选择 九云 的中高配月付套餐。因为 九云 支持 3-5 台设备并发，你可以和家人共享。由于它是标准线路，搭配中转架构，晚高峰的流媒体体验也能保持顺畅。

### 3. 不定期使用者（按量计费/一次性套餐）
九云 极少见地在平价机场中提供了**按量付费（一次性）套餐**。
- **适用人群**：平时不怎么翻墙，只有遇到突发需求（比如注册某个海外账号、临时找一点资料）时才需要用到节点的用户。
- **购买建议**：强烈推荐购买按量计费套餐。这种套餐虽然单GB流量的价格可能略高于常规包月，但它的最大优势是**不过期（或长期有效）**。你花几十块钱买的流量，只要没用完就可以一直留着，非常适合作为防失联的终极备用方案。

## 九云 订阅链接怎么用？各平台客户端配置指南

购买好套餐后，你会在 九云 的后台看到“一键订阅”或“复制订阅链接”的选项。请妥善保管这串链接，不要泄露给他人。以下是各平台主流客户端的配置指南。

### Windows 电脑端使用教程
在 Windows 系统上，目前最推荐的客户端是 **Clash Verge Rev** 或 **v2rayN**。
1. **Clash Verge Rev**：拥有现代化的 UI，支持多流媒体分流规则，非常适合搭配 九云 的智能路由策略。
   - 复制 九云 后台的 Clash 订阅链接。
   - 打开 Clash Verge Rev，进入“订阅”或“配置”页面。
   - 粘贴链接并点击“下载/导入”。
   - 导入成功后，在“代理”界面选择 九云 的节点即可。
   - 详细图文步骤请参考：[Clash Verge Rev 客户端配置指南](/tools/clash-verge-rev-complete-guide)。
2. **v2rayN**：适合喜欢极简、轻量级软件的老玩家。
   - 复制 v2ray 格式的订阅链接。
   - 打开 v2rayN，点击顶部菜单的“订阅” -> “订阅设置” -> “添加”。
   - 填入备注并粘贴链接，保存后点击“更新订阅”。
   - 详细图文步骤请参考：[v2rayN 新手配置教程](/tools/v2rayn-complete-setup-guide)。

### Mac 电脑端使用教程
Mac 平台同样推荐使用 Clash 核心的客户端（如 Clash Verge Rev 的 macOS 版本），操作逻辑与 Windows 版本几乎完全一致，导入 九云 订阅链接后即可使用。

### iOS 苹果手机端使用教程
iOS 端的绝对主力是 **Shadowrocket**（俗称小火箭）。你需要一个非国区的 Apple ID 来下载它。
1. 打开 Shadowrocket，点击右上角的“+”号。
2. 将“类型”选为“Subscribe（订阅）”。
3. 粘贴 九云 的订阅链接到“URL”一栏，备注填“九云”，然后点击右上角“完成”。
4. 向右滑动刚添加的订阅，点击“更新”。
5. 选择一个节点，打开顶部的全局开关即可。
   - 如果遇到下载或配置问题，请查看：[Shadowrocket 小火箭完整使用教程](/tools/shadowrocket-complete-setup-guide)。

### Android 安卓手机端使用教程
安卓端推荐使用 **Clash Meta for Android** 或 **v2rayNG**。只需复制订阅链接，在客户端中添加配置并更新即可。九云 的海外中转线路在这些主流客户端上都有极佳的兼容性。

## 九云 常见网络问题排查：为什么连不上或速度慢？

在使用 九云 的过程中，由于本地网络环境、运营商策略或客户端设置问题，偶尔可能会遇到连不上或速度变慢的情况。以下是针对 九云 线路特性的排查指南。

### 1. 为什么 九云 节点突然全部连不上了？
- **检查订阅是否过期**：登录 九云 官网后台，查看你的套餐是否已经到期，或者流量是否已经耗尽。
- **更新订阅链接**：有时候节点服务器 IP 被屏蔽，九云 官方会更换新的中转 IP 或入口。你只需要在客户端（如 Clash 或 Shadowrocket）中**手动更新一下订阅**即可获取最新节点。
- **检查本地网络**：确保你的本地 Wi-Fi 或蜂窝网络正常，尝试切换一下 4G/5G 和 Wi-Fi 看看是否恢复。
- **客户端代理冲突**：检查是否有其他 VPN 或代理软件正在同时运行。
- 更多详细排查步骤：[机场节点连不上？常见网络问题排查](/network/airport-not-working-troubleshooting)

### 2. 为什么 九云 的网速变慢了 / 看视频卡顿？
九云 采用的是标准线路的中转架构，通常速度是有保障的。如果出现速度慢的问题，请按照以下步骤排查：
- **切换节点**：有时候某个节点用的人太多，或者该节点对应的落地机（如某些热门的日本、香港节点）负载过高。利用 九云 的智能路由择优功能，或者手动切换到一个冷门节点（如新加坡、美国节点）。
- **避开极端晚高峰**：如果是在晚上 8 点到 11 点之间，可能是国际出口拥堵。虽然 九云 做了海外中转，但极端情况下仍可能受影响，尝试更换不同地区的节点。
- **修改客户端分流规则**：确保你的客户端使用的是“规则（Rule）”模式，而不是“全局（Global）”模式。全局模式会让国内网站也走 九云 节点，导致国内网站访问奇慢无比。
- 更多测速与优化技巧：[节点速度慢、卡顿怎么解决？](/network/airport-slow-speed-troubleshooting)

## 九云 流量与计费疑问解答

对于很多刚刚接触 九云 的朋友来说，流量计费规则可能会让人有些疑惑，特别是流量跑得太快或结转的问题。

### 流量为什么用得那么快？
- **测速软件**：频繁使用 Speedtest 等软件测速，一次测速可能会消耗几百MB甚至上GB的流量。
- **视频清晰度**：如果在 YouTube 等平台默认开启了 4K 或 1080p60，流量消耗会非常惊人。如果你购买的是 九云 6元档的基础套餐，建议将视频清晰度限制在 1080p 或 720p。
- **后台自动更新**：Windows、macOS 或手机上的 App 可能会在连接代理后自动在后台下载更新包，建议关闭系统自动更新，或者在客户端中设置直连规则。
- **节点倍率**：请留意 九云 后台节点列表中的“倍率”。如果某个节点的倍率是 1.5x 或 2.0x，意味着你实际下载 1GB 数据，套餐将扣除 1.5GB 或 2.0GB 流量。

### 九云 的常规套餐和按量计费怎么算？
正如我们在前面提到的：
1. **常规套餐**：**默认每月订单日重置流量**。例如你在 5月15日 购买了 100GB/月的套餐，那么在 6月15日，你的流量会重新变成 100GB。**当月未用完的流量（比如还剩 20GB）会被清零，不会累积到下个月**。
2. **一次性套餐（按量计费）**：购买此类套餐后，一次性给你固定的总流量（例如 500GB），没有强制的月度清零机制（具体有效期请参考 九云 官网一次性套餐的标注，通常为无使用期限或长达一年）。用多少扣多少，非常适合低频用户。

## 九云 常见问题答疑 (FAQ)

为帮助大家更好地上手，我们整理了用户在日常使用 九云 时最常问的 8 个问题。

**Q1：九云 支持解锁 Netflix、Disney+ 和 ChatGPT 吗？**
A：支持。九云 针对主流流媒体（Netflix、Disney+、YouTube Premium 等）和 AI 工具（ChatGPT、Claude、Midjourney）、社交平台（TikTok）均有专门的解锁优化。只要连接对应地区的节点即可顺畅使用。

**Q2：九云 限制几台设备同时使用？**
A：九云 允许 **3-5 台设备同时在线**。你可以将账号同时配置在自己的手机、电脑和平板上，或者与家人分享。但请注意不要超出限制，否则可能会触发官方的风控系统导致封号。

**Q3：为什么我购买了 九云 套餐，但状态还是未激活/不能用？**
A：请确认你的付款是否已经成功完成。有时候加密货币支付或第三方支付网关会有几分钟的延迟。如果等待10分钟后仍未到账，请带上支付截图通过 九云 后台提交工单，客服响应非常迅速。

**Q4：九云 会记录我的浏览记录吗？**
A：九云 作为一家正规运营的海外加速服务商，通常只记录用户的流量消耗总量用于计费，不会截取或记录用户通过加密协议传输的具体网页内容。建议日常使用时开启客户端的 TLS 加密，保障个人隐私。

**Q5：忘记续费，九云 的流量结转吗？**
A：官方规则非常明确：**常规套餐默认每月订单日重置流量，未用完的流量不会累积到下个月**。如果不续费，套餐到期后节点将立刻无法连接。

**Q6：在公司内网环境，九云 连不上怎么办？**
A：部分公司的企业内网会封锁常见的代理端口或域名。如果常规端口连不上，可以尝试更换 九云 订阅中的其他端口节点，或者联系 九云 官方客服咨询是否有专用的防封锁备用接口。

**Q7：九云 跑路风险大吗？能买年付吗？**
A：任何机场在理论上都存在不可抗力因素。虽然 九云 表现稳定、性价比极高，但我们一贯的建议是：如果你对价格非常敏感，建议先从 **6元/月的月付** 或 **季付** 体验；如果体验满意且希望节省费用，再考虑半年付或购买**按量计费套餐**。关于稳定性的长期跟踪，可以收藏我们的 [九云 评测与测速数据](/airport-observation/jiuyun-airport-comprehensive-review-and-streaming-guide)。

**Q8：九云 有专属的客服群或售后渠道吗？**
A：有的。九云 提供专业的客服支持。你可以在 九云 的官网用户面板（Dashboard）右下角找到在线客服入口，或者在“工单”系统中提交问题，客服通常会在工作时间内快速响应。如果是账单问题，必须通过官网工单处理。
