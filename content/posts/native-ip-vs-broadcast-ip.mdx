# 什么是原生 IP 与广播 IP？买机场如何区分和避坑？

在科学上网的圈子里，特别是当你为了看 Netflix 或注册海外 TikTok 账号而苦苦寻找 **流媒体解锁机场** 时，“**原生 IP (Native IP)**”这个词出现的频率极高。
很多机场老板会在宣传海报上打出巨大的标语：“全节点解锁流媒体，100% 纯净原生 IP ！”。但当你买回来连上美国节点，兴冲冲地打开 Netflix 时，却发现只能看自制剧。

为什么会这样？这是因为你买到的根本不是“原生 IP”，而是“广播 IP”。今天我们就来深度扒皮这两个概念，教你练就火眼金睛。

## 一、 核心概念：什么是原生 IP 和广播 IP？

世界上所有的 IP 地址都是由国际互联网机构分配的，每个 IP 都带有一个出生的“户口本”（WHOIS 信息），上面写着这个 IP 被分配到了哪个国家。

### 1. 原生 IP (Native IP)
原生 IP 的意思是：**这个 IP 的“户口本国籍”和它所在的“真实物理机房位置”是完全一致的。**
- 比如，机场老板在洛杉矶机房租了一台服务器，这台服务器分配到的 IP，去查它的注册信息，也是注册在美国洛杉矶。
- **优点**：流媒体平台（如 Netflix, Disney+）以及各种风控严格的游戏和 AI（如 ChatGPT），非常信任这类 IP。使用原生 IP，几乎不存在“由于地区不符而被封锁”的问题。

### 2. 广播 IP (Broadcast IP / Anycast IP)
广播 IP 的意思是：**这个 IP 的“户口本国籍”和它“真实的物理机房位置”是错位的。**
- 比如，机场老板在香港机房租了一台服务器。但是为了让你能看美国的 Netflix，老板通过 BGP 技术，把一个注册在美国的 IP，“广播”到了香港机房。
- 当你连接这个香港节点去查 IP 时，网站显示你在美国。但你的物理数据实际上并没有飞过太平洋，而是留在了香港。
- **优点**：机场的成本极低（不需要真的去拉跨洋带宽），而且用户会觉得延迟很低。
- **缺点**：这是对流媒体平台的“欺骗”。像 Netflix 这种技术极其牛逼的公司，一旦发现你这个所谓的“美国 IP”居然是从香港的数据中心发出请求的，会立刻把它拉黑。这就是为什么很多人买的所谓“流媒体解锁节点”，过几天就失效了。

## 二、 为什么广播 IP 看不了某些流媒体？

流媒体公司并不是只看你的 IP 归属地，它们有极其复杂的反作弊系统。它们会通过以下手段识破广播 IP：
1. **IP 库交叉比对**：流媒体公司会购买多家商业 IP 数据库（如 MaxMind），一旦数据库信息不一致，直接拉黑。
2. **Ping 值物理常识检测**：如果流媒体的美国 CDN 节点去 Ping 你的“美国 IP”，发现延迟高达 150ms（这说明你根本没在美国本土），流媒体就会判定你在使用广播技术伪装，从而拒绝服务。

## 三、 硬核鉴别：如何自己查节点是不是原生 IP？

不要听机场老板吹嘘，自己动手查才是硬道理。

### 方法 1：使用 BGP 路由探测网站（推荐新手）
你可以打开著名的 IP 查询网站 `bgp.he.net`。
连上你的节点后，在搜索框输入你当前的 IP。查看它的 `Country` 属性。
如果这里显示的国家，和你在 Google 里搜索 `my ip` 显示的国家**不一样**，那么 100% 是一条广播 IP！

### 方法 2：测延迟（利用物理常识）
挂上你的节点（比如美国节点），打开电脑自带的终端 (CMD/Terminal)。
输入 `ping 8.8.8.8`（这是 Google 的美国 DNS）。
- 如果延迟在 `5ms - 20ms` 左右，说明这个节点是真的在美国本土发出了请求，大概率是原生 IP 节点。
- 如果延迟高达 `100ms` 以上，说明这个节点其实人在香港或日本，它是广播过来的假美国 IP！
