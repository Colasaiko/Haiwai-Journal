# Hiddify 怎么导入机场订阅？Windows 与 Android 添加配置指南

Hiddify（基于 Sing-box 内核开发）作为一款新兴的多平台全能代理客户端，因其界面简洁、性能优秀且支持协议广泛，受到越来越多用户的青睐。不过对于刚刚接触 Hiddify 的用户而言，如何正确导入机场订阅（Subscription URL）、管理配置（Profile）以及选择合适的代理模式（系统代理/VPN模式）依然是一些常见的痛点。

本文将为您提供一份精简且直击要害的 Hiddify 导入机场订阅指南，专门针对 Windows 桌面端和 Android 移动端，帮助您快速上手，畅享网络世界。我们将从最基础的概念讲起，确保每一位新手都能无缝完成配置过程。

## 什么是机场订阅（Subscription URL）与 Profile？

在开始操作之前，彻底理解这两个核心概念将对您后续的操作大有裨益。很多新手在使用代理软件时感到困惑，往往是因为没有理清订阅和配置之间的关系。

### 1. 机场订阅（Subscription URL）

机场订阅，通常被称为 Subscription URL，是由您的代理服务提供商（俗称“机场”）生成的一串专属网址链接。这个链接并不是一个普通的网页，而是包含了一组甚至几百个服务器节点（Node）的详细连接信息的配置文件。
- **作用机制**：只需在客户端中导入此链接，客户端便能通过网络自动解析并拉取所有可用的节点。这免去了过去需要手动逐一复制粘贴各种复杂协议（如 Vmess, Trojan, Shadowsocks 等）字符串的繁琐过程。
- **格式要求**：目前市面上大多数机场都提供多种订阅格式。Hiddify 作为一个全能型客户端，具有极高的兼容性，无论您使用的是标准的 Base64 订阅、Clash 格式订阅，还是最新的 Sing-box 格式订阅，Hiddify 基本上都能完美识别并解析。

### 2. 配置（Profile）

在 Hiddify 的管理体系中，配置（Profile）是管理这些订阅信息和自定义规则的载体。
- **多配置管理**：您可以将一个 Subscription URL 保存为一个独立的 Profile。Hiddify 最大的优势之一是允许您同时添加多个 Profile。这意味着如果您购买了多个不同机场的服务，您可以为它们分别建立 Profile。
- **灵活性**：在实际使用中，您可以通过切换不同的 Profile 来快速切换不同机场的服务线路，相互之间完全独立，互不干扰。这对于需要高可用性和网络冗余的高级用户来说非常实用。

## 准备工作：一切顺利的基石

1. **下载并安装 Hiddify 最新版本**：前往 Hiddify 官方 GitHub Releases 页面，根据您的操作系统下载对应的安装包。对于 Windows 用户，建议下载最新版的 `.exe` 安装程序或便携版 `.zip`；对于 Android 用户，可以直接下载 `.apk` 文件进行安装，或者在 Google Play 商店搜索下载。
2. **获取并复制订阅链接**：登录您的机场服务提供商的后台面板，找到诸如“我的订阅”、“一键订阅”或“API 链接”等字样的板块。点击“复制订阅链接”。建议优先选择“Clash 订阅”或“Sing-box 订阅”格式，以获得最佳的兼容性。请确保将该完整链接准确无误地复制到您的设备剪贴板中。

## Windows 端导入订阅指南：桌面环境的最佳实践

在 Windows 电脑上使用 Hiddify 导入订阅的操作十分直观，其图形化界面设计极大地降低了学习成本。

### 第一步：新建 Profile 并导入链接

1. 打开 Hiddify 客户端主界面，您会看到一个极其清爽的仪表盘。点击左侧导航栏的 **“配置” (Profiles)** 选项，进入配置管理页面。
2. 在该页面的右上角，点击 **“+ 新建”** 或者直接点击界面中央显著的 **“添加配置”** 按钮，准备开始导入。
3. Hiddify 提供了多种导入方式。最便捷的方法是选择 **“从剪贴板添加”**——系统会自动读取您刚刚复制的 Subscription URL 并填入。如果您想手动操作，可以选择 **“手动输入”**，然后将链接粘贴到弹出的输入框中。
4. **命名配置**：系统通常会自动从订阅链接中抓取机场名称作为配置名，但为了后续管理方便，建议您手动将其修改为一个容易识别的名称，例如“香港专线-主用”或“备用机场B”。
5. 确认无误后，点击 **“保存”**。此时，Hiddify 会立即在后台尝试连接该链接并拉取所有节点信息。

### 第二步：更新节点与连通性验证

1. 订阅保存后，返回 **“配置”** 页面，找到刚才添加的 Profile。点击该配置右侧的 **“更新” (Update)** 按钮（通常表现为一个循环刷新的图标）。这一步至关重要，它能确保您的节点列表是最新的，避免因为机场服务端调整节点而导致连接失败。
2. 节点拉取成功后，切换回左侧导航栏的 **“主页” (Home)**。
3. 点击界面中央巨大的 **“启动”** 或 **“连接”** 按钮。如果一切正常，按钮状态会变为已连接，并显示实时的上传和下载速率。
4. **验证节点质量**：前往左侧栏的 **“节点” (Proxies)** 页面。在这里，您可以查看所有的服务器列表。点击上方的测速按钮，对所有节点进行延迟测试（Ping 或 URL Test）。系统会自动为您筛选出当前网络环境下延迟最低、最稳定的节点，您可以手动点击选中它。

## Android 端导入订阅指南：移动端的无缝体验

在安卓手机上，Hiddify 的界面设计与桌面端保持了高度的一致性，因此操作逻辑也非常相似。对于经常在移动端办公或娱乐的用户来说，掌握 Android 端的配置同样重要。

### 第一步：添加订阅配置

1. 在您的安卓手机上找到并打开刚刚安装好的 Hiddify 应用程序。
2. 将视线移至屏幕底部的导航栏，点击 **“配置” (Profiles)** 图标进入管理界面。
3. 点击屏幕右上角的 **“+”** 加号按钮，或者点击屏幕中间的“添加您的第一个配置”。
4. 在弹出的菜单选项中，优先选择 **“从剪贴板导入”**（请确保在此之前您已经在手机浏览器中登录了机场后台并复制了 Subscription URL）。如果剪贴板读取失败，可以选择 **“手动添加”** 并将链接粘贴进去。
5. 同样的，检查并修改配置名称，确认无误后点击 **“保存”**。

### 第二步：刷新订阅与选择最优节点

1. 在 Android 的配置列表中，找到刚添加的 Profile，点击其右侧的 **“刷新”** 图标。屏幕下方通常会弹出一个短暂的提示框，告知您“更新成功”或显示拉取到的节点数量。
2. 回到应用程序的 **“主页”** 标签卡，点击屏幕中央醒目的大圆形 **“连接”** 按钮。如果是第一次使用，Android 系统可能会弹出一个权限请求框，要求允许 Hiddify 创建 VPN 连接，请务必点击“允许”或“确定”。
3. 若需根据具体需求（如观看特定地区的流媒体）切换节点，请点击底部导航栏的 **“节点”** 页面。在这里，您可以直观地看到每个节点的延迟条带和具体数值。点击选中您偏好的地区节点即可瞬间完成切换。

## 进阶与排错：系统代理（System Proxy）与 VPN 模式（TUN）详解

在成功导入订阅并点击连接之后，很多用户可能会遇到这样一个问题：“为什么 Hiddify 显示已连接，但我的某些软件依然无法上网？”
要解决这个问题，您需要深入了解 Hiddify 是如何接管您的系统网络流量的。Hiddify 提供了多种流量接管模式，其中最核心、最常用的是 **系统代理 (System Proxy)** 和 **VPN 模式 (TUN 模式)**。正确区分和使用这两种模式，是熟练掌握 Hiddify 的关键。

### 1. 系统代理（System Proxy）
- **工作原理浅析**：当您在 Hiddify 中启用“系统代理”模式时，Hiddify 会悄悄地修改操作系统的全局网络代理设置（例如 Windows 中的 Internet 选项代理设置）。它实际上是在告诉系统：“如果有任何遵守代理规则的应用程序想要发送网络请求，请把请求先交给我（Hiddify）处理。”
- **适用场景**：最典型的应用场景就是**日常网页浏览**。绝大多数现代主流浏览器（如 Google Chrome, Microsoft Edge, Firefox, Safari 等）默认都会自动检测并严格遵守系统的代理设置。
- **显著优点**：由于只是修改了系统的转发规则，这种模式的资源占用非常低，且对操作系统网络底层的侵入性极小，不容易引发系统级别的网络故障。
- **致命缺点**：并非所有的软件都是“乖孩子”。许多应用程序（如大部分的网络游戏客户端、终端命令行工具如 Git/Curl、各种编程开发环境、部分 Windows UWP 微软商店应用等）在设计时就**不遵循**系统代理设置。它们会绕过代理，直接向目标服务器发送请求，这就会导致即使 Hiddify 处于连接状态，这些特定应用依然无法访问外网。

### 2. VPN 模式（TUN 模式）
- **工作原理浅析**：VPN 模式（在 Hiddify 的底层设置中通常被称为 TUN 模式）的工作方式则霸道得多。它通过在操作系统层面虚拟出一个全新的网卡（TUN 接口），并强行修改系统的路由表，从而**强制接管系统产生的所有网络流量**。不管应用程序本身是否支持或遵守代理设置，其发出的流量都必须经过这块虚拟网卡，进而被 Hiddify 截获并代理。
- **适用场景**：当您有**全局代理**的硬性需求时，例如玩外服游戏、使用终端命令行进行开发工作、或者发现某个顽固的特定软件始终不走代理时，TUN 模式是您唯一的选择。
- **显著优点**：能够做到真正意义上的“全局”代理，几乎所有层面的流量都能被有效截获、分流并处理，解决了部分软件不走代理的痛点。
- **缺点与注意事项**：
  - 在部分系统环境下（尤其是 Windows 平台），启用 TUN 模式可能需要安装额外的虚拟网卡驱动，或者每次启动 Hiddify 时都需要授予**管理员权限**（UAC 提示）。
  - 在一些网络拓扑结构复杂的局域网环境中（如公司内网、使用了其他虚拟机的环境），强制修改路由表可能会引起网络冲突，导致局域网设备互访失败。
  - 资源占用相比系统代理模式会略高一些。

**给您的实操建议：**
- **在 Android 移动端**：您无需过多纠结。出于 Android 系统的安全机制限制，Hiddify 默认且只能通过调用 Android 系统的 VPN API（即 VpnService）来实现代理功能。因此，只要您点击了连接，手机上的所有流量就已经处于 VPN 模式的保护下了，这是最稳妥且用户感知最好的一种方式。
- **在 Windows 桌面端**：建议根据您的实际使用情况进行灵活切换。如果您 90% 的时间只是看网页、查资料、刷流媒体视频，保持默认的 **系统代理** 模式就完全足够了。但如果您在玩 Steam 游戏、使用开发者工具，或者发现某个特定客户端无法正常连网，请果断进入 Hiddify 的设置页面，关闭系统代理，并开启 **TUN 模式（VPN 模式）**。

## 结语

通过阅读并实践这篇指南，相信您已经完全掌握了如何在 Hiddify 的 Windows 桌面端和 Android 移动客户端中高效、准确地导入机场订阅，并理解了 Subscription URL 和 Profile 之间的逻辑关系。

最后提醒一点，在使用过程中，请养成良好的习惯：定期在 **配置 (Profiles)** 页面点击更新按钮。因为机场服务商为了维护线路质量，可能会不定期地更换服务器 IP 或调整节点配置。保持节点列表处于最新状态，是保障您始终拥有稳定、高速且无缝网络体验的关键所在。现在，尽情享受 Hiddify 为您带来的畅快网络世界吧！
