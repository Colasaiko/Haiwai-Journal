在使用 Shadowrocket (常被称为“小火箭”) 时，大家最关心的往往是“哪个节点最快？”“怎么选节点才不会卡？”很多人习惯于一键测速，然后无脑选择延迟（Ping）最低的那个节点。但在实际体验中，你可能会发现延迟只有 20ms 的节点，看视频反而一直缓冲，而延迟高达 150ms 的节点却能秒开 4K 视频。

为什么会这样？在小火箭中，到底该怎么测速、怎么选择合适的节点？今天我们就来详细解析小火箭的节点测速机制，带你告别“唯延迟论”，真正选出适合自己的高质量节点。

## 1. 小火箭里的测速方式有哪些？

在 Shadowrocket 中，针对节点的测速主要有两种核心方式，它们分别代表了不同的网络指标：

### 1.1 延迟测试 (Ping / 连通性测试)
在首页节点列表的最上方，有一个“连通性测试”（通常点击左上角的测速图标或下拉刷新）。
- **含义**：它测试的是你的手机通过代理服务器，发送一个微小的数据包到目标服务器，然后再返回所花费的时间，单位是毫秒 (ms)。
- **结果**：如果通了，会显示数字，比如 `50ms`、`120ms`；如果不通，会显示 `Timeout`（超时）。
- **局限性**：这仅仅代表**路通不通**以及**路有多长**，并不代表**路有多宽**。

### 1.2 实际速度测试 (测速/下载测试)
小火箭支持对节点进行下载或真实速度测试。严格来说，小火箭内置的“延迟测试”主要测的是 TCP 或 ICMP 的响应时间。如果要测**带宽大小**（即真实网速），往往需要连接后使用 Speedtest 等工具，或者在一些提供测速面板的机场后台查看，甚至是直接打开流媒体观看体验。

## 2. 深入理解测速指标：不要被“最低延迟”骗了

在选节点时，我们通常会看到以下几种情况，理解它们代表的意义非常重要。

### 2.1 延迟 (Latency / Ping 值)
很多新手认为“延迟越低越好”。这句话只在特定场景下成立（比如打外服游戏）。
对于浏览网页、看视频来说，延迟的影响并没有那么大：
- **50ms 和 150ms 的区别**：在浏览网页时，你点击链接，50ms 的节点让你在 0.05 秒后收到响应，150ms 的节点在 0.15 秒后收到响应。对于人类的感知来说，这 0.1 秒的差距几乎是微乎其微的。
- **为何延迟低反而慢？**：一个香港节点的物理距离近，延迟可能只有 30ms，但如果它的带宽只有 5Mbps，而且同时有 1000 个人在挤，你看视频照样卡成 PPT。相反，一个美国节点物理距离远，延迟 150ms，但带宽高达 1000Mbps，且没什么人使用，它能让你轻松流畅观看 8K 视频。

**结论**：除了玩对外服网络要求极高的竞技游戏，**不要盲目追求极致的低延迟**。带宽和稳定性远比几十毫秒的延迟重要。

### 2.2 Timeout (超时)
如果你看到节点旁边显示 `Timeout`，意味着在这个特定的测试瞬间，你的设备无法通过该节点成功连接到目标测试服务器。
- **原因**：可能是节点已经失效、机场服务器宕机、你的本地网络波动，或者是小火箭的测速目标服务器暂时被墙或无响应。
- **怎么处理**：如果一两个节点 Timeout，不用管，直接忽略即可；如果大面积 Timeout，尝试更新订阅或检查本地网络。

### 2.3 连通性测试的“陷阱”
小火箭的默认连通性测试是向特定的 URL（如 Google 或 Cloudflare）发送请求。有些机场可能会针对这些常见的测速 URL 进行“劫持”或“优化”（俗称“测速造假”），让你看到极为漂亮的低延迟（比如显示 10ms），但实际用起来却非常慢。因此，真实的体验才是试金石。

## 3. 根据实际需求选节点：怎么选才最合适？

既然不能只看延迟，那我们该如何挑选日常使用的节点呢？答案是**根据你的实际需求场景来选择**。

### 3.1 视频与流媒体需求（YouTube, Netflix, Disney+）
看视频最需要的是**大带宽（速度）**和**流媒体解锁能力**。
- **地区选择**：首选提供原生 IP 或支持对应流媒体平台解锁的地区节点。比如看美区 Netflix，就必须选美国解锁节点；看港区 Disney+，就选香港或台湾节点。
- **速度要求**：只要实际带宽足够（一般 4K 视频需要 25Mbps 以上），延迟在 200ms 以内都不会影响观看体验。因为视频有缓冲机制，只要速度跟得上，哪怕一开始慢零点几秒，播放中途也会非常丝滑。
- **冷门节点有奇效**：如果热门地区（如香港、日本）在晚高峰卡顿，可以尝试切换到冷门地区（如新加坡、台湾甚至欧洲地区）。这些地区由于使用人数少，带宽充裕，反而能跑出更高的实际下载速度。

### 3.2 网页浏览与查资料
日常刷推特、查维基百科、使用 Google 搜索，这类操作需要的是**快速响应**和**稳定性**。
- **地区选择**：推荐选择物理距离较近的节点，如**香港、台湾、日本、韩国**。
- **指标参考**：此时延迟稍微有些参考价值，通常 100ms 以内的节点，网页秒开的体验会非常好。结合小火箭的自动测速功能，选择延迟表现稳定且不丢包的节点即可。

### 3.3 游戏需求
对于外服游戏，**延迟和丢包率**是唯二的标准。
- **专线节点**：最好使用 IPLC/IEPL 等专线节点。专线不过防火墙，延迟极低且极少丢包，是游戏的最佳选择。
- **地区选择**：必须选择与游戏服务器所在地区对应的节点。比如玩日服游戏，就选日本节点。
- **注意**：小火箭本身是代理软件，主要代理 TCP 数据。部分游戏依赖 UDP 协议，如果你的机场节点不支持 UDP 转发，或者小火箭未开启 UDP 转发功能，游戏可能无法正常连接。

## 4. 小火箭高效选节点与测速技巧总结

为了在日常使用中获得最佳体验，建议养成以下几个好习惯：

1. **善用“全局路由”策略**：平时建议将小火箭设置为“配置”（规则模式），这样国内流量直连，国外流量走代理，既省流量又不会影响国内 App 的速度。
2. **分组与排序**：在节点列表中，可以使用小火箭自带的排序功能（按延迟排序）。但这只是参考，重点是把平时好用的节点放在前面或者设置自动选择策略。
3. **不要频繁测速**：频繁测速不仅浪费流量，还可能对机场服务器造成负担。一般在感觉网速变慢、或者刚刚更新订阅后，进行一次连通性测试即可。
4. **实践出真知**：最靠谱的“测速”，就是直接打开一个 YouTube 4K 视频，右键（或点击设置）查看“详细统计信息 (Stats for nerds)”，看其中的 `Connection Speed`（连接速度）。这比任何软件的 Ping 值测试都真实可靠得多。

总结来说，在 Shadowrocket 中测速和选节点，**延迟只是参考，带宽才是王道，稳定压倒一切**。学会根据自己的使用场景（流媒体、网页、游戏）灵活切换地区节点，才能真正发挥出优质机场的全部实力。
