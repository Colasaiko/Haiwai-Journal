# 如何导入 Clash 订阅链接？Clash Verge Rev 电脑端一键配置教程

在各大论坛看到大牛们推荐的 **Clash 机场推荐**，兴奋地买了一个月套餐后，却发现后台只给了一长串像乱码一样的链接。
“这到底要怎么用啊？”这是无数翻墙小白发出的哀嚎。

不要慌！在 2026 年的今天，得益于优秀开源软件的进化，在电脑上配置代理已经变成了一件极其简单的事情。本文将以目前 PC 端最强大、最主流的 **Clash Verge Rev** 为例，教你如何 1 分钟内完成节点的导入和使用。

## 准备工作：下载并安装 Clash Verge Rev

*注：早期的 Clash for Windows (小猫咪) 已经停止维护，强烈建议不要再使用，以免遇到安全漏洞或新协议无法解析的问题。*

1. 打开浏览器，访问 GitHub 搜索 `Clash Verge Rev`，进入其官方 Releases 页面。
2. 根据你的电脑系统下载安装包：
   - Windows 用户：下载带有 `x64-setup.exe` 后缀的文件。
   - Mac 用户：根据你的芯片下载 `aarch64.dmg` (M芯片) 或 `x64.dmg` (Intel芯片)。
3. 安装并打开软件。此时软件界面默认是英文的。你可以点击左侧栏的 `Settings`，在 `Basic` 设置里将语言切换为 `中文`。

## 第一步：获取你的机场订阅链接

1. 登录你购买的机场官网后台。
2. 在首页面板（Dashboard）上，通常会有一个区域叫 **“一键订阅”** 或 **“捷径”**。
3. 找到并点击 **“复制 Clash 订阅链接”**（注意：千万不要点复制 V2Ray 或 Base64 链接，Clash 只能识别 YAML 格式的订阅）。
4. 此时，你的系统剪贴板里已经有了一长串 `https://...` 开头的链接。

## 第二步：在软件中导入链接

1. 打开刚才安装好的 Clash Verge Rev。
2. 点击左侧导航栏的 **“订阅 (Profiles)”**。
3. 在顶部输入框中，**粘贴** 你刚才复制的机场订阅链接。
4. 点击右侧的 **“导入 (Import)”** 按钮。
5. 稍等几秒钟，当你看到列表中出现了一张带有你机场名字的卡片，并且上面显示了流量信息（比如 Used: 5GB, Total: 100GB）时，说明导入成功！
6. **极其重要的一步**：在那个生成的卡片上 **右键点击 -> 选择“使用 (Use)”**。卡片变成蓝色或者出现一个勾，才代表当前正在使用这套配置。

## 第三步：开启代理并选择节点

1. 点击左侧导航栏的 **“代理 (Proxies)”**。
2. 你会看到界面上出现了密密麻麻的国家节点（如香港、美国、日本）。
3. 在最上方的**“策略组 (Proxy Group)”**中，找到主节点选择框（通常叫 `PROXIES` 或者 `节点选择`），点击展开，然后选择一个你看着顺眼的节点（比如 `香港 IPLC 01`）。
4. 最后一步：点击左侧导航栏的 **“设置 (Settings)”**，找到 **“系统代理 (System Proxy)”**，将其开关**打开**。

**恭喜你，你已经成功翻过高墙了！** 现在你可以打开浏览器，在地址栏输入 `youtube.com` 测试一下是否能顺利播放视频。

## 常见报错解决

- **提示 Invalid Config 或 导入失败**：
  这说明你复制的链接不是给 Clash 用的，或者你买的机场协议太旧。请回机场后台确认你点的是“复制 Clash 订阅”。
- **节点全红，Timeout**：
  请检查你电脑的右下角系统时间是否准确。如果时间偏差超过 2 分钟，Clash 将无法连接任何节点。
