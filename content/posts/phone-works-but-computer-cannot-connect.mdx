手机连接机场一切正常，但把同样的订阅链接放到电脑上却无法翻墙，这是非常典型且高频的网络异常现象。这种情况一般可以排除节点或机场服务端宕机的问题，说明核心故障点出在电脑的本地环境、客户端配置或是系统网络设置上。本文将从浅入深，提供一套系统的排查逻辑，帮助你快速定位并解决 Windows 和 macOS 上的连接障碍。

## 一、排查工作流：第一时间的快速验证

在深入复杂的系统设置之前，我们应该先通过简单的对比和验证，缩小故障范围。你可以按照以下决策树的逻辑来初步诊断：

1. **确认环境一致性**：电脑和手机是否连接在同一个 Wi-Fi 网络下？如果手机使用移动数据可以连接，连上 Wi-Fi 就断开，说明可能是宽带运营商封锁或是路由器 DNS 污染。
2. **核对订阅有效性**：确保电脑端的订阅链接与手机端完全一致，并且已经在电脑端成功获取了最新的节点列表。有时候可能只是电脑端很久没有点击“更新订阅”导致节点失效。
3. **切换节点测试**：尝试连接不同的节点。部分节点可能对某些客户端的协议兼容性有差异，切换不同国家、不同倍率的节点观察是否有数据传输。
4. **验证真伪代理**：在电脑客户端开启代理后，访问局域网内的路由器后台或是国内常用大厂网站（如百度、淘宝）。如果国内网站打得开，但国外网站打不开，通常是代理路由规则或核心机制未生效；如果国内外网站全都无法访问，说明系统网络已经被破坏或是端口被完全拦截。

如果以上基础验证无法解决问题，请进入下面的详细排查步骤。

## 二、核心客户端与代理机制排查

很多时候，问题出在代理软件本身或者其接管系统流量的方式上。

### 1. System Proxy（系统代理）是否成功接管
主流客户端（如 Clash、v2rayN）默认使用“系统代理”模式。开启后，软件会自动修改 Windows 或 macOS 的系统代理设置。
- **Windows**：打开“设置” > “网络和 Internet” > “代理”。检查“使用代理服务器”开关是否已经自动打开，并且地址通常为 `127.0.0.1`，端口对应你客户端的本地端口（例如 7890 或 10808）。如果发现软件开启了但系统这里没变，说明软件没有权限修改系统设置。
- **macOS**：进入“系统设置” > “网络” > 选择当前网络 > “详细信息” > “代理”。检查 Web 代理 (HTTP) 和 安全 Web 代理 (HTTPS) 是否被勾选并指向本地环回地址。

**解决方案**：以管理员身份（Windows 右键“以管理员身份运行”）重新打开代理软件，或者在软件内部找到“清除系统代理”后重新勾选。

### 2. 尝试启用 TUN 模式 (虚拟网卡)
系统代理只能接管通过 HTTP/SOCKS5 发起请求的流量，部分应用（如命令行工具、某些游戏客户端、甚至是 UWP 应用）不走系统代理。如果网页打不开，但软件内日志显示有节点连接，可能是流量根本没进代理软件。
- 此时，强烈建议开启客户端的 **TUN 模式**。TUN 会在系统内创建一张虚拟网卡，强制接管所有本地流量。
- 在开启 TUN 模式前，请确保在客户端内安装了相应的 Service 或虚拟网卡驱动（如 Wintun），并给予管理员权限。对于经常遇到奇怪断网情况的用户，了解 [什么是 TUN 模式及其优势](/network/what-is-tun-mode) 会非常有帮助。

### 3. 客户端版本兼容性与内核问题
机场通常会定期升级服务端的协议（如升级到较新的 Shadowsocks-2022、VLESS 或 Hysteria2）。如果你的电脑客户端已经大半年没更新，而手机客户端是自动从应用商店更新的最新版，就会导致电脑端内核无法解析新的协议格式。
- **排查方法**：查看电脑端代理软件的报错日志。如果出现大量的 `unknown protocol` 或 `unsupported cipher`，请立刻前往 GitHub 下载最新版本的客户端，并更新其核心组件（Core）。

## 三、Windows 系统专项排查

Windows 环境相对复杂，多重安全软件和网络组件都可能成为拦截代理流量的元凶。

### 1. Windows 防火墙与杀毒软件拦截
很多第三方杀毒软件（如 360、火绒、迈克菲 McAfee、卡巴斯基）或者 Windows 默认的 Defender 防火墙，会把代理客户端识别为恶意网络拦截工具，从而阻断其在本地监听端口（如 7890）。
- **测试方法**：暂时完全关闭所有的第三方杀毒软件，并临时关闭 Windows Defender 防火墙的“专用网络”和“公用网络”防护，然后重启代理软件，看是否恢复正常。
- 如果确认是此问题，请将代理软件的主程序 `.exe` 文件添加到杀软和防火墙的**白名单（排除项）**中。

### 2. 系统时间与时区不同步
基于 V2Ray/Xray 内核的协议（如 VMess），对客户端和服务端的时间误差极其敏感。如果误差超过 90 秒，鉴权就会失败，导致完全无法连接。
- 手机通常会自动通过基站同步精确时间，而电脑如果主板电池没电或是禁用了时间同步，可能会慢几分钟。
- **解决方案**：在 Windows 设置中搜索“日期和时间”，点击“立即同步”。确保时区设置正确（如 UTC+8 北京时间），并且时间精确到秒。

### 3. 网络适配器与 DNS 缓存干扰
有时电脑的 DNS 缓存记录了错误的 IP，或者网络适配器本身出现配置紊乱。
- 打开命令提示符（CMD，以管理员身份运行），执行以下命令清理网络环境：
  ```cmd
  ipconfig /flushdns
  netsh winsock reset
  ```
- 执行完毕后必须重启电脑。这能解决 80% 因为底层网络协议栈损坏导致的“玄学”连接问题。想了解更多网络重置技巧，可参考 [Windows 常见网络故障修复指南](/network/windows-network-fix-guide)。

## 四、macOS 系统专项排查

虽然 macOS 生态相对封闭，但网络设置上的冲突同样不少。

### 1. 代理残留与网络配置文件损坏
如果在 Mac 上曾经安装过其他代理工具（如 Surge、ShadowsocksX-NG、VPN 软件等）且没有卸载干净，可能会导致隐藏的代理规则冲突。
- **排查方法**：进入“网络”设置，删掉当前连接的 Wi-Fi 配置文件，然后重新添加一个。或者检查“系统设置” -> “网络” -> “VPN 与过滤器”，看是否有遗留的其他软件正在拦截流量。

### 2. 权限问题
macOS 对网络扩展（Network Extension）和辅助程序的权限管控非常严格。如果你使用的是 ClashX Pro 或 Surge，在首次运行或更新后，可能会弹出请求网络配置权限的提示。如果不小心拒绝了，软件就无法生效。
- **解决方案**：进入 macOS 的“系统设置” -> “隐私与安全性”，向下滚动查看是否有关于该代理软件被拦截的提示，点击“允许”。

## 五、进阶情况与极端场景

如果你已经排查了以上所有内容，电脑依然无法连接，可以考虑以下几个进阶可能：

1. **运营商的 DPI 设备差异**：极少数情况下，同一条宽带下，电脑产生的流量特征（如特定浏览器的 Client Hello 特征）被当地运营商的深度包检测（DPI）系统精准识别并阻断，而手机端的特征没有触发拦截。可以尝试在客户端内开启 TLS 指纹伪装（如 uTLS 设置为 Chrome）。
2. **路由器层面的 Mac 地址限速/屏蔽**：检查家里的主路由器后台，是否开启了针对这台电脑的家长控制、网站过滤或是局域网隔离。
3. **UWP 应用限制（仅限 Windows）**：如果你发现电脑的浏览器能翻墙，但是 Windows 商店、Xbox 应用连不上，这是由于 Windows 限制了 UWP 应用访问本地回环地址（Loopback）。你需要使用工具（如 EnableLoopback）来解除 UWP 应用的网络隔离，具体操作可阅读 [如何解除 UWP 应用的本地网络隔离](/network/uwp-loopback-exemption)。

## 常见问题解答 (FAQ)

**1. 手机和电脑连同一个 Wi-Fi，手机测速能跑满，电脑为什么非常卡顿？**
这通常是因为电脑端的代理客户端使用的路由规则不合理，导致大量原本该直连的国内流量（如视频缓冲、下载）也绕道了国外节点。请检查并更新电脑客户端的“规则文件”（Ruleset），并确保工作在“规则模式”（Rule/PAC）而非“全局模式”（Global）。

**2. Windows 电脑打开代理后，微信能发消息，但网页全都打不开？**
这一般是因为微信并不依赖 HTTP 系统代理，而是直接通过 TCP/IP 握手。网页打不开说明你的浏览器无法连接到 `127.0.0.1` 的本地代理端口。最常见的原因是 Windows 代理设置被安全软件篡改，或者端口被其他程序（如虚拟机、Hyper-V）占用。建议尝试更改代理软件的默认监听端口（比如从 7890 改为 10809），并重启软件。

**3. 开启 TUN 模式后电脑直接断网，显示“无 Internet 访问”，怎么解决？**
TUN 模式接管了底层网卡，如果 DNS 设置不当会引发断网。请检查代理软件内的 DNS 设置，确保启用了客户端内置的 DNS（如 Fake-IP 模式），并且 Windows 物理网卡的 DNS 处于“自动获取”状态。不要手动将物理网卡 DNS 写死为 8.8.8.8，这在 TUN 模式下容易导致路由死循环。

**4. 为什么电脑休眠唤醒后，原本正常的机场就死活连不上了？**
休眠唤醒会导致物理网卡的 IP 重新分配，而此时代理软件的虚拟网卡或代理服务可能没有从挂起状态恢复过来。解决方法很简单：彻底退出电脑右下角的代理客户端（Quit），然后再重新双击启动，通常即可恢复网络连接。

**5. macOS 下浏览器提示 "ERR_PROXY_CONNECTION_FAILED" 是什么情况？**
这个报错明确表示浏览器试图连接系统设置里指定的代理服务器（通常是本机的某个端口），但没有得到响应。多数是因为你把代理软件退出了，但 macOS 的“系统代理”勾选框没有自动取消。去“网络”->“代理”中手动取消勾选 HTTP/HTTPS 代理即可恢复直连上网，或者重新打开你的代理软件。

**6. 机场客服说节点已经换了新 IP，手机更新订阅后能用，电脑更新了还是旧节点？**
这可能是电脑端的代理客户端存在顽固的缓存问题。建议在软件的订阅设置中，找到“强制更新”或“不使用缓存更新”选项。如果依旧无效，可以尝试在本地找到客户端的配置文件夹（如 `.config/clash`），手动删除旧的 `.yaml` 配置文件，然后再重新从 URL 下载。

**7. 电脑一直提示时间不同步导致无法连接，但我主板时间看起来是对的？**
肉眼看时间是对的，可能实际上差了几十秒。V2Ray 协议通常要求误差在 90 秒内，建议打开 https://time.is 网站，该网站会精确告诉你当前电脑时间与标准时间相差多少。如果误差过大，必须去系统设置中强制进行 NTP 网络时间同步。
