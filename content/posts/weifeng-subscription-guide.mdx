想要在各个设备上顺畅使用微风网络，学会正确导入订阅链接是第一步。本文将手把手教您如何在微风网络官网获取专属订阅地址，并详细演示将其导入到 Clash Verge、Shadowrocket（小火箭）以及 v2rayN 等主流客户端的具体步骤。无论您使用的是 Windows 还是 iOS 设备，通过本指南，您都能快速完成配置，充分发挥微风网络“全IPLC专线、不限制设备同时接入、不限速”的极致优势，开启稳定低延迟的科学上网体验。

## 一、 如何获取微风网络订阅链接？

在使用任何客户端之前，您都需要先从微风网络的官方网站获取您的个人专属订阅链接。由于微风网络主打**全IPLC专线**，提供极其稳定的跨境连接服务，因此请务必妥善保管您的订阅地址，切勿随意分享给他人，以免账号被封禁或流量被盗用。

1. **登录官方网站**：首先，使用您的账号密码登录微风网络的官网后台面板。
2. **找到仪表盘（Dashboard）**：登录成功后，您会默认进入仪表盘页面。在页面的显眼位置，通常会有一个“一键订阅”或“快速导入”的区域。
3. **复制订阅地址**：
   - 如果您是电脑端用户，可以点击“复制订阅地址”按钮，直接将通用的订阅链接复制到剪贴板。
   - 如果您使用的是特定的客户端，比如 Clash 或 Shadowrocket，您可以点击相应的“导入到 Clash”或“导入到 Shadowrocket”按钮，系统会自动尝试唤醒对应的软件进行一键导入。
   - **注意**：订阅链接中包含您的个人专属 Token 密钥（例如 `https://api.weifeng.example/sub?token=您的专属密钥`，请不要使用真实链接中的内容泄露给他人），这是您连接服务器的凭证。

若您在获取订阅链接时遇到打不开官网的情况，可以参考我们的 [微风网络最新官网地址发布页](/posts/weifeng-latest-url) 获取备用访问方式。

## 二、 Clash Verge (Windows/Mac) 导入指南

Clash Verge 是目前 Windows 和 macOS 平台上最受欢迎、界面最现代化的 Clash 内核客户端之一，非常适合配合微风网络的不限速 IPLC 专线使用。

### 1. 软件下载与安装
如果您还没有安装 Clash Verge，请先前往其 GitHub 发布页下载对应操作系统的安装包并完成安装。启动软件后，建议在“设置（Settings）”中将语言切换为中文（System Language -> 中文），以便于后续操作。

### 2. 导入微风网络订阅
- 打开 Clash Verge，点击左侧导航栏的“**配置（Profiles）**”选项。
- 在配置页面顶部，找到“**新建（New）**”按钮，并在弹出的输入框中，将您刚刚从微风网络官网复制的**订阅链接**粘贴进去。
- 粘贴完成后，点击旁边的“**导入（Import）**”按钮。
- 此时，软件会开始从微风网络的服务器下载配置文件。下载成功后，配置列表中会出现一个新增的项目。
- **关键一步**：用鼠标**右键点击**这个新下载的配置文件，选择“**使用（Use）**”。配置文件前出现蓝色小圆点或背景变色，即表示激活成功。

### 3. 选择节点与开启代理
- 点击左侧导航栏的“**代理（Proxies）**”。您现在应该能看到微风网络提供的所有节点列表了。得益于其全 IPLC 专线，您可以挑选延迟最低的节点（通常带有延迟数值显示）。
- 选择您喜欢的节点后，回到左侧导航栏，点击“**设置（Settings）**”。
- 找到“**系统代理（System Proxy）**”开关，将其**打开**。现在，您的电脑就已经成功连接到微风网络，可以自由访问国际互联网了。

## 三、 Shadowrocket 小火箭 (iOS/iPadOS) 导入指南

Shadowrocket（俗称小火箭）是 iOS 生态中最强大的代理工具之一。由于微风网络**不限制设备同时接入**，您可以放心地在您的 iPhone 和 iPad 上同时配置和使用。

### 1. 准备工作
请注意，Shadowrocket 在中国大陆区的 App Store 是无法搜索和下载的。您需要使用非中国大陆地区（如美区、港区）的 Apple ID 登录 App Store 进行购买和下载。关于如何获取海外 Apple ID，可以查阅相关的网络教程，或者查看我们关于 [iOS 客户端推荐及 Apple ID 获取指南](/posts/ios-proxy-clients-guide)。

### 2. 快速一键导入
最简单的方法是在您的 iPhone 上使用 Safari 浏览器登录微风网络官网，然后在仪表盘点击“**一键导入到 Shadowrocket**”。系统会提示是否要在 Shadowrocket 中打开，点击“允许”，小火箭就会自动添加订阅配置。

### 3. 手动复制链接导入
如果您无法使用一键导入，也可以手动操作：
- 在微风官网复制通用订阅链接或 Shadowrocket 专用订阅链接。
- 打开 Shadowrocket 客户端。
- 点击右上角的“**+**”号添加节点。
- 将“类型（Type）”选择为“**Subscribe（订阅）**”。
- 在“URL”一栏中，粘贴您刚刚复制的微风网络订阅链接。
- “备注（Remarks）”一栏可以随意填写，比如“微风网络”。
- 点击右上角的“**完成（Save）**”。

### 4. 更新订阅与开启
- 回到 Shadowrocket 首页，向右滑动刚刚添加的“微风网络”订阅项，点击出现的“更新（Update）”按钮。稍等片刻，节点列表就会自动展开。
- 在节点列表中，选择一个心仪的 IPLC 专线节点（点击节点名称，前面会出现小黄点）。
- 最后，将最上方的“**未连接（Not Connected）**”开关向右拨动，开启连接。首次开启可能会弹出添加 VPN 配置的系统提示，点击“Allow（允许）”并验证密码/面容即可。

## 四、 v2rayN (Windows) 导入指南

v2rayN 是一款老牌且极其稳定的 Windows 客户端，体积小巧，占用资源低，同样能够完美支持微风网络的订阅格式。

### 1. 下载与解压
从 v2rayN 的官方 GitHub 仓库下载最新的 release 压缩包（通常下载带有 `Core` 字样的版本，如 `v2rayN-Core.zip`，这样就不需要额外下载内核了）。下载后解压到一个固定的文件夹中，双击运行 `v2rayN.exe` 即可启动。

### 2. 添加微风网络订阅
- 启动 v2rayN 后，程序图标通常会隐藏在电脑右下角的系统托盘中，双击图标打开主界面。
- 点击主界面顶部菜单栏的“**订阅（Subscription）**” -> “**订阅设置（Subscription Settings）**”。
- 在弹出的窗口中，点击左下角的“**添加（Add）**”按钮。
- **别名（Remarks）** 填写“微风网络”。
- **地址（URL）** 栏中，粘贴您从官网复制的订阅链接。
- 点击“确定（OK）”保存设置。

### 3. 更新订阅并启动节点
- 回到主界面，点击顶部菜单栏的“**订阅（Subscription）**” -> “**更新订阅（不通过代理）（Update subscription without proxy）**”。
- 等待几秒钟，主界面下方会提示更新成功，并且节点列表中会刷出大量的微风网络节点。
- 任意选择一个节点，**右键点击**它，选择“**设为活动服务器（Set as active server）**”（或者直接按下键盘上的回车键）。
- 最后，找到系统托盘右下角的 v2rayN 图标，**右键点击**它。找到“**系统代理（System Proxy）**”，选择“**自动配置系统代理（Set system proxy）**”。图标变成红色即表示代理已经成功开启。

如果您想了解更多适合 Windows 的代理软件，可以阅读我们的 [2026年最佳 Windows 科学上网客户端推荐](/posts/best-windows-proxy-clients)。

## 五、 订阅更新与常见问题排查（节点为空怎么办？）

虽然微风网络提供极具性价比的高质量线路，但在日常使用中，您可能会遇到一些小问题，最常见的就是“节点列表为空”或“节点全部超时连不上”。这通常是因为订阅信息过期或者本地网络出现了波动。

### 如何手动更新订阅？
机场的服务端会不定期地优化线路、更换被封锁的节点 IP。因此，定期更新订阅是保持网络畅通的好习惯。
- **Clash Verge**：在“配置（Profiles）”页面，找到微风网络的配置，点击右侧的刷新按钮（圆形箭头图标）即可手动更新。
- **Shadowrocket**：在首页找到订阅名称，向右滑动，点击“更新（Update）”。
- **v2rayN**：点击菜单栏“订阅” -> “更新订阅”。

### 遇到节点为空或全部 Timeout 怎么解决？
1. **检查订阅是否过期**：登录微风网络官网，检查您的套餐流量是否已经耗尽，或者套餐时间是否已经到期。如果已过期，续费后重新更新订阅即可。
2. **更换网络环境更新**：如果在当前 Wi-Fi 下更新订阅失败，尝试切换到手机热点，然后再执行一次“更新订阅”操作。有时候是因为宽带运营商屏蔽了订阅域名的解析。
3. **关闭代理更新**：在更新订阅时，确保您当前的客户端代理开关处于**关闭状态**。特别是 v2rayN 用户，一定要选择“更新订阅（不通过代理）”。
4. **重新复制订阅链接**：如果您的订阅链接已被重置（例如您在官网点击了重置订阅链接防止泄露），旧的链接就会失效导致节点为空。此时必须回到官网，复制最新的订阅链接，并在客户端中**删除旧配置，重新导入新链接**。
5. **校准系统时间**：绝大多数代理协议（如 Vmess、Trojan）严格依赖于系统时间。如果您的电脑或手机时间与标准时间误差超过 1 分钟，就会导致连接失败。请确保您的设备开启了“自动设置时间”功能。

## 常见问题解答 (FAQ)

### 1. 微风网络的订阅链接可以分享给朋友用吗？
不可以。微风网络的订阅链接包含您的专属验证凭证，且后台有严格的风控系统。虽然微风网络**不限制设备同时接入数**（适合您自己的多台电脑、手机、平板同时使用），但如果系统检测到您的订阅链接在极短时间内于异地多个不同 IP 出现异常高频连接，极有可能触发风控导致账号被暂时冻结。建议妥善保管您的订阅地址。

### 2. 为什么我导入 Clash Verge 后，有些节点显示“Timeout”？
显示 Timeout 意味着当前网络无法测速该节点。这可能是因为节点正在维护，或者是您本地的网络环境到该节点的路由暂时受阻。微风网络提供全 IPLC 专线，整体稳定性极高，您可以尝试手动更新一下订阅，或者直接切换到其他未显示 Timeout 的节点使用。通常情况下，挑选延迟最低的节点体验最好。

### 3. 在小火箭中更新订阅提示“无效的 URL”是怎么回事？
这种情况通常是因为您复制订阅链接时不够完整，遗漏了字符，或者是复制了错误的链接格式（比如错把 Clash 的订阅链接填入了普通的 Subscribe 选项）。请重新前往微风网络官网，仔细复制“通用订阅”或“V2ray/Shadowrocket 订阅”链接，然后重新添加到小火箭中。

### 4. 微风网络真的不限速吗？我下载文件感觉没有达到宽带上限？
微风网络官方承诺所有套餐均**不限速**，采用高质量的专线带宽。但实际测速结果会受到多方面因素影响，包括您本地宽带运营商的国际出口质量、当前连接节点的繁忙程度，以及目标网站（如您正在下载文件的服务器）本身的带宽限制。如果您觉得速度不佳，建议切换几个不同地区的节点（如从香港切换到日本）再进行尝试。

### 5. v2rayN 开启系统代理后，部分国内软件无法上网怎么办？
这通常是因为路由规则没有设置正确。在 v2rayN 中，建议将底部的“路由（Routing）”选项设置为“**绕过大陆（Bypass LAN and mainland）**”。这样设置后，访问国内网站（如百度、淘宝）将不经过代理直接连接，而只有访问海外网站时才会走微风网络的节点，既能保证国内软件的正常使用，也能节省您的机场流量。

### 6. 我的订阅链接不小心泄露了，应该如何补救？
如果您怀疑自己的微风网络订阅链接被他人知晓或盗用，请立即登录微风网络官网后台。在“仪表盘”或“账户设置”页面，寻找类似“**重置订阅链接**”或“**更新 Token**”的按钮。点击重置后，旧的订阅链接将立刻失效。之后，您需要使用新生成的订阅链接，到所有的客户端中重新导入配置。

### 7. Clash Verge 导入微风网络订阅后，怎么开启开机自启？
为了方便日常使用，您可以设置 Clash Verge 开机自动运行。在软件左侧导航栏点击“**设置（Settings）**”，在“通用设置（General）”板块中找到“**开机自启动（Start on Boot）**”开关并将其开启。这样每次打开电脑后，您就不需要再手动运行软件，可以直接科学上网了。
