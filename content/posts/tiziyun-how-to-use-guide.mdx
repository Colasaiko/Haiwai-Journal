## 梯子云 怎么用？新手快速入门指南

欢迎使用梯子云。对于刚刚接触梯子云的新用户来说，了解基础的使用流程可以大幅减少摸索的时间。梯子云采用高性能 Shadowsocks (SS) 协议架构，拥有多入口智能调度的基础中转方案，并且不限制同时在线设备数，非常适合作为日常的主力节点供应商。

使用梯子云的核心流程可以概括为以下三步：
1. **注册与购买**：前往 [梯子云官网](/brands/tiziyun) 注册账号，并根据您的实际需求选购合适的套餐（支持按量计费或月付）。
2. **获取订阅链接**：在用户中心找到属于您的专属订阅链接（也称为订阅地址），这是将节点导入客户端的关键。
3. **配置客户端**：下载并安装适合您操作系统的代理客户端（如 Windows/Mac 上的 Clash Verge Rev，iOS 上的 Shadowrocket），在客户端中粘贴并更新订阅链接，即可开始无缝连接全球网络。

在您正式开始配置之前，我们强烈推荐您阅读 [梯子云 全面评测](/airport-observation/tiziyun-shadowsocks-vpn-review) 了解其在日常网页访问、跨境电商及轻度社交中的实际表现，确保您对其基础中转网络和解锁能力有一个直观的认知。

## 梯子云 订阅链接怎么用？(各平台客户端配置指南)

获取梯子云的订阅链接后，您需要借助第三方代理客户端才能连接网络。由于梯子云采用了标准且高度兼容的 Shadowsocks (SS) 协议，目前市面上绝大多数主流客户端均能完美支持。

以下是针对不同操作系统的客户端配置教程：

### Windows & macOS 推荐：Clash Verge Rev
Clash Verge Rev 是目前 PC 端体验最优秀的客户端之一，支持规则分流和多节点测速。
1. 下载并安装 Clash Verge Rev。
2. 复制梯子云后台的订阅链接。
3. 在软件界面左侧选择“配置(Profiles)”，粘贴链接并点击“导入(Import)”。
4. 切换到“代理(Proxies)”页面，选择您需要的节点。
- 详细图文教程请参考：[Clash Verge Rev 完整使用指南](/tools/clash-verge-rev-complete-guide)

### iOS 推荐：Shadowrocket (小火箭)
Shadowrocket 是一款轻量、强大的 iOS 代理软件，能够轻松处理 SS 协议并提供出色的电池续航表现。
1. 在非国区 App Store 购买并下载 Shadowrocket。
2. 打开软件，点击右上角的“+”号。
3. 类型选择“Subscribe(订阅)”，在 URL 栏粘贴梯子云订阅链接。
4. 点击完成，软件会自动获取节点列表，打开顶部的连接开关即可。
- 详细图文教程请参考：[Shadowrocket 小火箭完整配置指南](/tools/shadowrocket-complete-setup-guide)

### Android 推荐：v2rayN / Clash for Android
对于 Android 和部分 Windows 用户，v2rayN 也是一个久经考验的选择。
- 详细图文教程请参考：[v2rayN 完整设置指南](/tools/v2rayn-complete-setup-guide)

## 为什么连不上 / 速度慢？(常见排查指南)

梯子云的“基础中转方案 + 多入口智能调度”理论上能提供优秀的稳定性。但如果您在使用过程中遇到连不上或速度缓慢的情况，可以按照以下步骤进行排查：

### 1. 订阅链接未更新或已失效
**表现**：所有节点突然全部超时（Timeout），无法连接任何网页。
**排查**：梯子云会不定期维护入口和节点，导致旧的节点信息失效。请在您的客户端中执行**“更新订阅 (Update)”**操作。若依然无效，请前往官网确认您的套餐是否已过期或流量是否已耗尽。

### 2. 客户端时间不同步
**表现**：SS 协议对时间敏感，如果设备时间与标准时间误差较大，会导致认证失败，节点表现为连接断开。
**排查**：请确保您的电脑或手机时间已开启“自动同步时间”功能，校准时间后重启客户端再试。

### 3. 多入口智能调度的瞬时波动
**表现**：刚刚连接时速度较慢，或在观看视频中途出现短暂卡顿。
**排查**：梯子云采用智能调度机制，有时入口切换会带来短暂的延迟。通常等待几秒钟网络即可恢复。若长时间速度不佳，请尝试在客户端中手动切换到其他地区的节点（如从香港节点切换至日本或新加坡节点）。
- 更多速度排查技巧，请参阅：[机场节点速度慢的排查与优化技巧](/network/airport-slow-speed-troubleshooting)

### 4. 软件冲突或本地网络限制
**表现**：仅在公司网络或特定 Wi-Fi 下无法连接，切换至手机热点后正常。
**排查**：这通常是因为本地网络屏蔽了特定端口，或者电脑上同时运行了其他代理/加速器软件（如游戏加速器、某些杀毒软件），导致路由冲突。
- 深度故障排查可参考：[连不上节点？机场完全不工作的排查指南](/network/airport-not-working-troubleshooting)

## 流量为什么用得快？/ 按量计费怎么算？

很多用户在使用按量计费套餐或流量包月时，会感觉流量消耗速度超乎预期。在梯子云，**全节点统一 1x 计费倍率**，这意味着无论您连接哪个国家的节点，消耗 1GB 实际流量，系统就只扣除 1GB 流量，这在很大程度上避免了“高倍率刺客”。

那么流量为什么还会用得快？主要有以下原因：

1. **流媒体自动高画质**：梯子云完整解锁了 Netflix 和 YouTube 等流媒体。当网络极佳且不限速时，YouTube 会默认自动加载 4K 画质。观看一小时 4K 视频大约会消耗 7-10GB 流量。如果您希望节省流量，请在播放器内手动将画质锁定在 1080P 或 720P。
2. **后台自动更新**：PC 端的 Windows Update、Steam 游戏更新，或手机端的 App Store 自动更新，在连接代理后可能会跑满带宽进行下载。建议在下载大文件前断开代理或设置绕过规则。
3. **按量计费结算机制**：请注意，按量计费的流量扣除会有轻微的延迟，您在后台看到的可能不是实时的剩余流量。

## 梯子云 常见问题 FAQ

### Q1: 梯子云 支持几台设备同时在线？
**A**: 梯子云采用高性能 Shadowsocks (SS) 协议，官方政策为**不限制同时在线设备数**。您可以在手机、电脑、平板甚至路由软路由上同时配置并使用，非常适合多设备重度用户。但请注意合理使用，避免账号被系统判定为恶意分享。

### Q2: 为什么我的 ChatGPT 提示 Access Denied 或无法访问？
**A**: 梯子云原生支持完整解锁 ChatGPT 等前沿 AI 工具。如果您遇到阻断，请首先确认您是否连接了原生解锁节点（通常是美国、台湾或日本节点）。若问题依旧，请尝试在客户端中开启全局模式（Global Mode）或清除浏览器 Cookie 后刷新。

### Q3: 梯子云 适合用来玩外服游戏吗？
**A**: 梯子云提供的是基础中转方案，虽然能够满足日常网页访问、轻度社交和视频流媒体，但不建议作为专业的游戏加速器使用。外服游戏对 UDP 转发和极致的低延迟要求极高，若您是硬核玩家，建议购买专属游戏加速器。

### Q4: 节点列表里的“多入口智能调度”是什么意思？
**A**: 多入口智能调度意味着您连接的并不是单一的物理服务器，而是一个集群入口。系统会根据当前网络的拥堵情况，自动为您分配最优的中转线路。这种架构能够有效防御网络封锁和单点故障，提供全程不限速的体验。

### Q5: 梯子云 的节点怎么全部超时（Timeout）了？
**A**: 如果出现大面积超时，请首先**更新您的订阅链接**。梯子云为了保证网络质量，可能会更换服务器 IP 或入口地址，如果不更新订阅，客户端仍会尝试连接已下线的旧服务器。详见本文的 [排查指南](#为什么连不上--速度慢常见排查指南)。

### Q6: 按量计费套餐有使用期限吗？
**A**: 通常情况下，大部分按量付费（不限时流量包）只要您的账号处于活跃状态，流量就不会过期。但具体政策请以梯子云官网当前发布的说明为准。

### Q7: 为什么连接梯子云后，收发国内邮件或访问国内网站变慢了？
**A**: 这通常是因为您的客户端（如 Clash 或 Shadowrocket）设置为了“全局代理(Global)”，导致所有国内流量也绕道海外节点。请将客户端模式切换回“规则(Rule)”或“配置”模式，即可实现国内直连、海外走代理的智能分流。

### Q8: 梯子云 支持退款吗？
**A**: 关于退款政策，各机场均有严格的审计标准。一般情况下，只要您的流量消耗在规定的微量范围内（如 1GB 以内）且在购买后极短时间内，可尝试提交工单（Ticket）与客服沟通。具体请参考官方退款规则。
