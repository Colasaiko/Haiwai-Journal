## 刚买完机场，拿到的订阅链接到底是什么？

很多新手用户在第一次购买科学上网服务（俗称“机场”）后，都会在后台看到一长串以 `http` 或 `https` 开头的网址，这被称为“订阅链接”（Subscription Link）。如果你是刚刚接触这个领域，可能会有些摸不着头脑：这个链接能直接在浏览器里打开吗？为什么要分成不同格式的订阅？

简而言之，订阅链接是一个包含了大量服务器节点配置信息的远程列表。你的代理客户端（比如 Clash、Shadowrocket 等）通过读取这个网址，就能自动下载并解析出所有可用的节点、加密方式、端口以及密码等技术细节，而无需你手动逐个填写。这不仅极大地降低了使用门槛，也方便机场主随时更新节点信息。当节点发生故障或增加新线路时，用户只需在客户端内点击“更新订阅”，所有最新的节点列表就会同步到本地。

不同的代理工具往往使用不同的配置文件格式。因此，机场后台通常会提供多种不同格式的订阅链接，例如 Clash 订阅、V2Ray 订阅、Surge 订阅等。在使用前，你必须确保复制的订阅链接与你正在使用的客户端相匹配。如果你还在迷茫如何开始，可以先阅读我们的 [新手入门指南](/start-here)，里面梳理了科学上网的基础概念。

接下来，我们将详细讲解在各大主流平台上，如何将获取到的订阅链接正确导入到对应的客户端中。

## Windows 平台：Clash Verge Rev 导入方法

在 Windows 系统上，目前最受推荐的图形化客户端是 Clash Verge Rev。它基于强大的 Clash Meta 内核（现更名为 mihomo），不仅界面美观，还支持各种最新的协议。如果你想深入了解该软件的所有高级功能，请参考这篇详尽的 [Clash Verge Rev 完整使用指南](/tools/clash-verge-rev-complete-guide)。

### 步骤一：获取 Clash 格式订阅

首先，登录你的机场后台面板，找到“一键订阅”或类似的选项。点击展开后，选择“复制 Clash 订阅”或“导入到 Clash”。如果你看到的是一个普通的链接，请直接复制它。注意，切勿复制错误格式的链接，例如复制了 V2Ray 格式的链接放入 Clash 中，客户端将无法解析，并会提示报错。

### 步骤二：在 Clash Verge 中添加配置

1. 打开 Clash Verge Rev 客户端，在左侧导航栏中找到并点击“配置”（Profiles）面板。
2. 在页面顶部，你会看到一个输入框，通常提示填写 URL。将刚才复制好的 Clash 订阅链接粘贴到这个输入框中。
3. 粘贴完成后，点击右侧的“导入”（Import）按钮。此时，客户端会在后台向该链接发起请求，下载对应的配置文件。
4. 几秒钟后，下方列表中会出现一个新生成的配置文件，通常会以你的机场名称命名。点击该文件，将其选中（背景颜色或左侧状态会发生改变，表示已激活）。

### 步骤三：开启系统代理

配置导入并选中后，点击左侧导航栏的“代理”（Proxies）页面。在这里，你会看到所有的节点列表。此时不要忘记最后一步：回到“设置”（Settings）页面，找到“系统代理”（System Proxy）选项，并将其开关打开。一旦开启，Clash 就会接管系统的网络流量，你就可以顺利访问国际互联网了。

如果导入过程中遇到问题，可以查看我们专门针对 Clash 订阅报错的分析文章：[Clash 导入订阅常见问题及解决方法](/clash/how-to-import-clash-subscription)。

## 苹果 iOS 平台：Shadowrocket (小火箭) 导入方法

对于 iPhone 和 iPad 用户，Shadowrocket（因其图标常被称为“小火箭”）无疑是装机量最大、兼容性最强的代理软件。由于苹果 App Store 的区域限制，你需要使用非中国大陆区（如美区或港区）的 Apple ID 才能下载。详细的下载与高阶配置说明，请访问 [Shadowrocket 小火箭配置全指南](/tools/shadowrocket-complete-setup-guide)。

### 步骤一：选择适合小火箭的订阅

Shadowrocket 对协议的支持非常广泛。在机场后台，你可以选择“复制 Shadowrocket 订阅”。如果没有这个特定选项，复制“V2Ray 订阅”、“SSR 订阅”或者“Clash 订阅”其实都可以，小火箭都有较好的兼容解析能力。但为了保险起见，优先选择官方标明适配 Shadowrocket 的链接。

### 步骤二：添加节点与更新

1. 打开 Shadowrocket 应用首页，点击右上角的“+”号添加新节点。
2. 在“类型”（Type）选项中，点击并将其更改为“Subscribe”（订阅）。
3. 在“URL”一栏中，粘贴你刚刚复制的订阅链接。
4. “备注”（Remarks）栏可以随意填写，比如你的机场名字，方便日后管理。然后点击右上角的“完成”（Done）保存。
5. 返回首页后，屏幕上会出现你刚才添加的订阅组。向右滑动该条目，点击“更新”（Update），或者直接在首页列表下拉刷新，软件便会开始获取节点。

### 步骤三：连接并测试

节点刷新出来后，点击你需要使用的节点（前方会显示一个勾选标志）。随后，在首页最上方找到未连接状态的开关，将其拨向右侧开启。首次开启时，iOS 系统会弹出一个提示框，要求添加 VPN 配置（Add VPN Configurations），点击“Allow”并输入锁屏密码或者通过 Face ID 验证即可。之后打开浏览器访问 Google 测试是否成功连通。

## Windows 平台老牌经典：v2rayN 导入方法

尽管 Clash 阵营十分强势，但 v2rayN 作为老牌的 Windows 客户端，凭借其轻量级和稳定的特点，依然拥有庞大的用户群体。特别是对于使用旧版本 Windows 系统或者偏好传统界面的用户，v2rayN 是个非常可靠的选择。关于这款软件的详细剖析，推荐阅读 [v2rayN 完整设置与优化指南](/tools/v2rayn-complete-setup-guide)。

### 步骤一：复制正确链接格式

与 Clash 不同，v2rayN 属于 v2ray 生态系统。在机场后台，你需要明确选择“复制 V2Ray 订阅”或“复制 v2rayN 订阅”。切忌在此处使用 Clash 的 YAML 格式订阅链接，v2rayN 无法识别。

### 步骤二：订阅设置与导入

1. 打开 v2rayN，在主界面顶部的菜单栏中点击“订阅分组”（Subscription group），然后选择“订阅分组设置”（Subscription group settings）。
2. 在弹出的窗口中，点击“添加”（Add）。
3. 别名（Remarks）可以输入机场名，可选地址（URL）处粘贴你的 V2Ray 订阅链接。勾选启用（Enable），然后点击“确定”（Confirm）。
4. 设置完成后，返回主界面，在菜单栏点击“订阅分组”，选择“更新全部订阅（不通过代理）”（Update subscription without proxy）。
5. 稍等片刻，主界面列表里就会自动刷出大量节点。

### 步骤三：开启路由模式

选中一个延迟较低的节点（按下 Enter 键或右键选择设为活动服务器）。接下来最关键的一步是设置底部的路由模式。在 v2rayN 主界面的下方，有一个系统代理（System proxy）的选项卡，通常有三个选项：清除系统代理、自动配置系统代理、不改变系统代理。你需要选择“自动配置系统代理”。同时，将路由规则（Routing）设置为“绕过局域网及大陆地址”（Bypass LAN and mainland China），这样国内流量就不会走代理，保证了日常访问速度。

## 安卓平台：v2rayNG 导入方法

v2rayNG 是 Android 平台上与 v2rayN 对应的开源客户端，以其清爽的界面和出色的稳定性广受好评。安卓平台上的操作相对比较直接，不会像 iOS 那样受到严格的应用商店区域限制，用户可以通过 GitHub 或者 Google Play 轻松获取。

### 具体导入步骤

1. 登录机场，复制好 V2Ray 格式的订阅链接（同 v2rayN）。
2. 打开 v2rayNG 应用，点击界面左上角的“三横线”菜单图标，选择“订阅设置”（Subscription settings）。
3. 点击右上角的“+”号添加新的订阅。备注填入机场名称，地址栏粘贴刚刚复制的链接。保存后返回主界面。
4. 在主界面右上角，点击三个点组成的菜单图标，选择“更新订阅”（Update subscription）。
5. 节点列表更新后，挑选一个顺眼的节点点击选中（左侧会出现一根细条高亮指示）。
6. 最后，点击界面右下角的“V”字圆形悬浮按钮。如果是第一次使用，安卓系统会提示连接请求，允许后，图标变成连接状态，即可开始畅游网络。

## 全新聚合利器：Hiddify 与 sing-box 导入方法

随着新型代理协议的发展，以 sing-box 核心为代表的下一代客户端逐渐崭露头角。它们在应对复杂网络环境时表现更为出色。Hiddify Next 是一款跨平台（支持 Windows, macOS, Linux, Android, iOS）的多合一客户端，极大地简化了配置流程。了解更多可以查看 [Hiddify 使用全攻略](/tools/hiddify-complete-guide)。

### Hiddify Next 导入教程

Hiddify 的最大优势在于它的极简操作，很多时候你甚至不需要区分订阅格式，它能自动解析绝大多数常规链接。
1. 获取你的机场订阅链接（任何通用格式均可尝试，推荐使用 Clash 或通用订阅）。
2. 打开 Hiddify，在首页的正中央，点击“添加新配置”大按钮（或者是右上角的 + 号）。
3. 选择“从剪贴板添加”（如果链接已经复制）或者手动选择“输入配置链接”并粘贴进去。
4. 导入成功后，它会作为一个配置组保存在首页。点击连接按钮，Hiddify 就会智能选择最佳节点并建立连接。

### sing-box 客户端解析

相比之下，原生的 sing-box 客户端（特别是对于普通用户）门槛较高，因为它使用的是专属的 JSON 格式配置文件，并且很多机场暂时并未直接提供 sing-box 的订阅格式。通常，如果你想使用原生 sing-box 客户端，需要借助第三方的订阅转换工具，将普通的 V2Ray 或 Clash 订阅转换成 sing-box 标准 JSON，然后再粘贴进客户端。由于过程较为繁琐，对于新手，我们更推荐直接使用 Hiddify 来体验 sing-box 内核的强大性能。

## 常见问题 (FAQ)

### 1. 为什么导入订阅链接后提示“下载配置失败”或“Timeout”？
这通常是因为你的本地网络无法直接访问该订阅链接的服务器。如果机场提供了“备用订阅链接”，请尝试更换。或者暂时连接其他可用的代理环境后再进行更新。另外，请确保你的系统时间与当前标准时间一致，时间误差过大会导致连接失败。

### 2. Clash 和 V2Ray 的订阅链接可以混用吗？
不可以。这是两种完全不同的配置语言。Clash 使用基于 YAML 格式的配置，而 V2Ray 使用 base64 编码的配置流。如果你把 V2Ray 订阅丢给 Clash 客户端，它会立刻报错提示格式错误。请务必在机场后台选择与客户端相对应的链接。

### 3. 我可以把订阅链接分享给朋友使用吗？
绝大多数商业机场都严格禁止分享订阅链接。后台系统会监控连接的 IP 数量，如果检测到同一订阅链接在短时间内出现大量异常 IP 登录，你的账号可能会被自动封禁。为了避免不必要的损失，请勿公开你的链接。

### 4. 节点列表突然变空了，怎么办？
这说明本地的配置文件可能已损坏，或者是你在无意中清除了缓存。解决方法很简单：回到客户端的订阅管理/配置管理界面，找到该机场的条目，点击“更新”按钮重新拉取一次节点即可。

### 5. 为什么我的所有节点全红，或者延迟显示为 Timeout？
首先，检查是否你的机场套餐已经过期或者流量耗尽。其次，确认你导入订阅的操作是否正确。如果所有节点仍然不可用，可能是机场遭受了墙的干扰封锁，这时候需要耐心等待机场主修复，并频繁尝试更新订阅获取新域名节点。

### 6. 更新订阅时，提示证书验证失败是怎么回事？
部分机场的订阅服务器 SSL 证书可能过期，或者配置不当。在某些客户端（如 Shadowrocket 或 Clash Verge 中），可以找到跳过证书验证（Skip Cert Verify）的开关，开启后再尝试更新。不过，最好还是向机场客服反馈此问题。

### 7. 我买的机场没有提供 Shadowrocket 订阅，我该选哪个？
Shadowrocket 兼容性极强。如果后台没有显式标注，你可以依次尝试复制 V2Ray 订阅、SSR 订阅或 Clash 订阅导入进去，大概率是可以被正常识别并解析出节点的。

### 8. 每隔多久需要更新一次订阅？
没有硬性要求，但建议养成习惯。当遇到当前节点速度变慢、连接断开时，第一反应应该是去更新一下订阅。很多机场主会定期清理被封锁的节点并上线新节点，如果不更新，你使用的将永远是旧列表。建议至少每周更新一次，以保持最佳的体验。
