# Clash 的规则模式、全局模式和直连模式有什么区别？

在使用 Clash (无论是 Clash for Windows, Clash Verge 还是 ClashX) 时，新手最容易在主界面的“模式 (Mode)”选项上犯迷糊。
你会看到三个核心选项：**规则 (Rule)**、**全局 (Global)** 和 **直连 (Direct)**。选错了模式，轻则导致国内网站加载缓慢，重则直接断网。

今天我们就用最通俗易懂的人话，为你彻底讲清这三大模式的区别与使用场景。

## 一、 直连模式 (Direct)：关闭魔法的“隐身衣”

### 什么是直连模式？
在直连模式下，Clash 会**完全停止工作**。它会让你的所有网络流量（包括浏览器、游戏、微信）全部绕过代理服务器，直接连接到目标网站。

### 什么时候用？
1. **完全不需要翻墙时**：比如你要长时间打国内游戏（如英雄联盟国服），为了防止 Clash 产生哪怕 1ms 的干扰，你可以切换到直连模式。
2. **下载国内大文件时**：如果你在用百度网盘下载几十个 G 的电影，切换到直连模式最稳妥。

*注：在日常使用中，如果你想关闭代理，其实直接点击“Quit”退出 Clash 软件是更干脆的做法。*

## 二、 全局模式 (Global)：强行翻墙的“推土机”

### 什么是全局模式？
全局模式极其霸道。一旦开启，你电脑上的**所有流量**（不管你是访问国外的 Google，还是访问国内的淘宝、微博）都会被**强制打包发往你在 Clash 中选中的那个节点**（比如美国节点）。

### 什么时候用？
1. **某些国外小众网站打不开时**：有些国外的网站并没有被收录进你的“规则列表”里。在规则模式下，Clash 会以为这是个国内网站而不走代理，导致你打不开。这时候切成“全局模式”，就能强制用美国 IP 访问它。
2. **需要伪装 IP 时**：比如你要登录某些严格检测 IP 的海外银行账号，或者注册某些特殊应用，全局模式能确保你的真实国内 IP 绝对不泄露。

**⚠️ 警告：** 平时千万不要挂着全局模式！因为这会导致你访问国内网站时，数据先绕到美国再绕回中国，速度极其缓慢，而且会疯狂消耗你的机场流量。

## 三、 规则模式 (Rule)：智能分流的“交通警察” (最常用)

### 什么是规则模式？
这是 Clash 的灵魂所在，也是**强烈建议 99% 的时间保持开启**的模式。
在规则模式下，Clash 就像一个智能的交通警察，它手里拿着一本“黑白名单字典”（这本字典通常是由你的机场在订阅链接里写好的）。

- 当你访问 `Google.com`，警察一查，是国外的，放行！走代理通道。
- 当你访问 `Bilibili.com`，警察一查，是国内的，拦截！让你走本地直连通道。
- 当你访问 `Netflix.com`，警察一查，需要流媒体解锁，直接把你分配到专用的“流媒体节点”。

### 为什么它是最完美的模式？
**既省流量，又快！** 看国外视频享受极速翻墙，刷国内抖音和微信依然是本地最快网速，两者互不干扰。

## 总结：抄作业指南

- 日常冲浪、看视频、刷推特：**永远选【规则模式】 (Rule)**。
- 遇到某个死活打不开的外国冷门网站：**临时切到【全局模式】 (Global)**，看完再切回规则。
- 打国内网游：**选【直连模式】 (Direct) 或直接退出软件**。

## 数据驱动的决策参考模型

机器倍率是一个经常被新手忽视的计费参数。当倍率为 2.0 时，实际消耗的套餐流量将是下载数据的两倍。这通常出现在成本高昂的优质专线上，受众需要根据后台面板的说明合理估算真实可用数据量。

除了核心的代理功能，很多服务商开始提供定制化的客户端以降低小白小伙伴的入门门槛。这类傻瓜式客户端去除了复杂的路由配置，只需一键登录即可采用。然而，这往往也牺牲了一定的自定义灵活性。

在多设备场景下（如手机、电脑、软路由同时在线），你需要关注套餐支持的并发设备数限制。部分严格的服务商如果发现设备超限，会自动阻断连接甚至封禁账号。合理规划不同设备的互联网接驳点极其重要。

有时即便线路本身正常，本地的 DNS 污染也会导致网页无法正常解析。启用客户端内置的 Fake-IP 模式或者配置可靠的远程 DNS 查询，允许有效解决大部分“连接建立失败”的玄学故障。
