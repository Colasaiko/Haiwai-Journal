- **流媒体全家桶**：全面覆盖 Netflix、Prime Video、BBC、Abema、TVer 等主流流媒体平台，原生 IP 直通，带来极致的高清观影体验。

- **商务家庭优选**：采用高性能协议，多国节点可选，且不限制在线设备数，无论是商务团队还是家庭全员使用都毫无压力。

## 隐形人 套餐怎么选？

隐形人 提供了多种周期套餐以及按量付费（一次性）套餐，最低价格在 ¥24/月左右。它家提供的都是标准线路，但得益于全链路专线架构与云端多链路即时优化，即便是标准套餐也能带来旗舰级的体验。

### 1. 月付套餐（约 ¥24/月起）
适合刚开始使用 隐形人 的新用户或者流量需求稳定的轻中度用户。每月拥有固定的流量额度。得益于不限制在线设备数，可以在手机、电脑、平板甚至路由器上同时使用。

### 2. 长周期套餐（季付 / 半年付 / 年付）
如果在使用一个月后觉得 隐形人 的速度和稳定性符合要求，强烈建议升级到长周期套餐。单月折算下来成本更低。适合重度流媒体观众（Netflix、Prime Video 追剧）或者有大流量下载需求的用户。

### 3. 一次性 / 按量计费套餐
隐形人 提供按量计费（Pay-as-you-go）套餐。流量不过期，用多少扣多少。
- **适合人群**：平时很少翻墙，只有偶尔需要查阅资料、调用 ChatGPT 4 API 或者作为主用机场的备用节点的用户。

建议：如果是重度 AI 开发者（如频繁调用 Hugging Face 或大模型 API），按量计费可能会因为瞬间流量消耗大而不划算，推荐使用包月套餐；如果是偶尔使用，一次性套餐是极佳的备用选择。

## 隐形人 订阅链接怎么用？

购买套餐后，你可以在 隐形人 官网后台找到**订阅链接**（Subscribe URL）。隐形人 支持多种主流客户端，请根据你的操作系统选择相应的软件进行配置。

### Windows 系统
Windows 系统推荐使用 **Clash Verge Rev** 或 **v2rayN**。
- **Clash Verge Rev** 是目前最流行的 Clash 客户端分支，界面美观，支持多种规则配置。复制 隐形人 的 Clash 订阅链接，在客户端的“配置”或“订阅”选项中粘贴并更新即可。
- 详细教程：[Clash Verge Rev 完全配置指南](/tools/clash-verge-rev-complete-guide)
- **v2rayN** 是轻量级的选择。复制 隐形人 的 V2Ray 订阅链接，在客户端中选择“从剪贴板导入批量 URL”即可。
- 详细教程：[v2rayN 完全设置指南](/tools/v2rayn-complete-setup-guide)

### macOS 系统
推荐使用 **Clash Verge Rev**（支持 macOS 版）或者 Surge。配置方式与 Windows 类似，复制订阅链接后导入客户端即可。同样可参考 [Clash Verge Rev 指南](/tools/clash-verge-rev-complete-guide)。

### iOS / iPadOS (苹果手机与平板)
推荐使用 **Shadowrocket**（俗称小火箭）或者 Quantumult X。
- **Shadowrocket**：在应用主界面点击右上角的 `+`，类型选择 `Subscribe`，粘贴 隐形人 的订阅链接，保存并更新即可。
- 详细教程：[Shadowrocket 完全配置指南](/tools/shadowrocket-complete-setup-guide)

### Android (安卓系统)
推荐使用 **Clash for Android** 或 **v2rayNG**。同样是复制对应的订阅链接，导入软件后台更新节点即可。

## 为什么连不上 / 速度慢？排查与解决方法

尽管 隐形人 采用了全链路专线架构和云端多链路即时优化，但在实际使用中，仍可能会遇到连不上或速度慢的情况。

### 1. 订阅未更新或节点失效
节点配置可能会有变动，请尝试在客户端内**更新订阅**。如果使用的是 Clash 类客户端，可以尝试重启软件或清除系统 DNS 缓存。

### 2. 账号流量耗尽或套餐过期
请登录 隐形人 官网，检查你的账号流量是否已经用完，或者套餐是否已经到期。对于一次性按量付费用户，请确认账户余额和剩余流量。

### 3. 本地网络环境问题
有时宽带运营商会对特定连接进行干扰，或者本地路由器的 DNS 设置有问题。你可以尝试切换 Wi-Fi 与移动数据，以排查是否是本地网络导致的问题。

### 4. 客户端设置错误
检查你的客户端代理模式是否设置正确。通常建议选择“规则模式（Rule）”或“自动路由”，如果设置为“全局直连（Direct）”，则流量不会经过 隐形人 的节点。

## 流量为什么用得快？节点倍率与计费说明

很多用户会觉得流量用得快，这通常与流媒体观看、软件更新以及节点计费倍率有关。

### 统一 1x 计费倍率
隐形人 的一大优势是**节点统一 1x 计费倍率**。这意味着你下载 1GB 的数据，后台就只扣除 1GB 的流量额度。你不必像在其他机场那样，为了寻找低倍率节点而反复切换，所有国家和地区的节点都能安心使用。

### 流量消耗大户
如果你发现流量消耗异常，请检查以下几点：
- **流媒体清晰度**：使用 隐形人 观看 Netflix 或 Prime Video 的 4K 视频，每小时大约会消耗 7GB - 10GB 流量。原生 IP 直通会默认加载最高画质，请根据流量情况调整清晰度。
- **后台自动更新**：系统更新（Windows Update / macOS 更新）、应用商店自动下载以及后台云盘同步（如 OneDrive、iCloud）都会悄无声息地消耗大量流量。
- **不限制在线设备数**：由于 隐形人 允许多设备同时在线，如果家里多台设备同时看视频，流量消耗是成倍的。

建议在不需要代理的场景下（如访问国内视频网站、下载国内大型游戏更新），确保客户端处于“规则模式”而非“全局代理模式”。

### 1. 隐形人 支持哪些流媒体解锁？

### 2. 开发者和 AI 用户使用 隐形人 体验如何？
非常优秀。隐形人 完整支持 ChatGPT 4、GitHub Copilot 以及 Hugging Face。全链路专线架构保证了低延迟的 API 调用，非常适合需要高稳定性连接的开发者。

### 3. 隐形人 限制在线设备数量吗？
不限制在线设备数。你可以同时在手机、电脑、平板和路由器上配置 隐形人 的订阅，非常适合拥有众多设备的极客、商务团队或家庭共享使用。

### 4. 一次性（按量计费）套餐有时效限制吗？
通常来说，按量计费套餐的流量是不过期的，直到你用完为止。非常适合作为备用机场或者流量需求极低的轻度用户。具体规则以 隐形人 官方后台说明为准。

### 5. 为什么 隐形人 的节点价格比普通直连机场贵一点？
最低 ¥24/月的价格其实性价比很高。因为 隐形人 提供的是全链路专线架构，没有普通中转或直连机场容易出现的晚高峰拥堵、断流问题。结合不限制设备数和统一 1x 倍率，综合体验远超市面上的廉价机场。

### 6. 我在 iOS 上怎么使用 隐形人？
对于 iOS / iPadOS 用户，建议在 App Store（需使用非中国大陆区 Apple ID）下载 Shadowrocket。下载后，在 隐形人 后台复制订阅链接并导入即可。详细步骤见本文上方的 [Shadowrocket 配置指南](/tools/shadowrocket-complete-setup-guide)。

### 7. 使用 隐形人 会泄露我的真实 IP 吗？
只要你的客户端配置正确（例如开启系统代理并处于规则或全局代理模式），隐形人 的高性能协议会加密你的流量，并将你的请求通过其海外节点发出，目标网站只能看到节点的 IP，不会泄露你的真实 IP。

### 8. 遇到节点全红测速超时怎么办？
请首先在客户端中手动“更新订阅”。如果是最近本地网络波动，可尝试重启电脑或手机、切换 Wi-Fi。如果问题依旧，请前往 隐形人 官网查看是否有维护公告，或查阅 [机场连不上排查指南](/network/airport-not-working-troubleshooting)。
