## 开启 TUN 模式失败的核心原因与快速自检

在使用 Clash Verge Rev 等主流代理客户端时，TUN 模式因其能够接管全局流量、实现真正的系统级代理而备受青睐。很多用户在开启 TUN 模式时，经常会遇到开关自动回弹（无法开启）、开启后整机断网，或者直接提示“wintun.dll 加载失败”等报错。

导致这些故障的核心原因通常集中在四个方面：软件未获取足够的系统管理员权限、Service Mode 未正确安装或正在运行错误版本、系统中存在其他 VPN 虚拟网卡导致的驱动冲突，以及操作系统的 DNS 配置与防病毒软件的拦截。要彻底解决这一问题，我们需要从底层权限控制入手，逐一排除虚拟网卡和网络协议栈的干扰。如果您刚开始使用这款软件，建议先阅读我们的 [Clash Verge Rev 完整使用指南](/tools/clash-verge-rev-complete-guide)，了解基本配置后再进行深度排查。

## 什么是 TUN 模式？为何它对系统环境要求苛刻？

TUN 模式（Tunnel 模式）是一种通过在操作系统中创建虚拟网卡（Virtual Network Interface Card），将所有网络层的 IP 数据包强制路由到代理客户端的技术。与传统的系统代理（System Proxy）不同，传统代理仅在应用层修改系统的 HTTP/HTTPS 代理设置，这种方式对许多不遵守系统代理环境变量的软件（如命令行工具、某些游戏客户端和特定的开发环境）无效。

而 TUN 模式在网络协议栈的底层工作，它能够真正实现全端口、全协议的流量接管。为了完成这种底层操作，Clash Verge 必须在 Windows 系统中加载 Wintun 驱动程序并创建虚拟网络接口。这属于操作系统的核心级操作，因此对运行权限、驱动环境以及网络配置有着极其严格的要求。任何第三方安全软件的拦截，或者残留的其他虚拟网卡驱动，都会导致创建失败。

## 排查步骤一：解决管理员权限与 Service Mode 未授权问题

Clash Verge 打开 TUN 模式最常见的阻碍就是权限不足。即使您的 Windows 账户是管理员，出于 UAC（用户账户控制）的保护，直接双击运行的程序依然只拥有普通用户权限。

### 1. 手动以管理员身份运行客户端
每次开启软件时，右键点击 Clash Verge 的快捷方式，选择“以管理员身份运行”。如果您发现 TUN 模式可以正常开启了，说明这就是权限问题。为了避免每次都右键操作，您可以右键点击快捷方式 -> 属性 -> 兼容性 -> 勾选“以管理员身份运行此程序” -> 点击确定。

### 2. 正确安装和启用 Service Mode
为了避免反复请求管理员权限，Clash Verge 提供了 Service Mode（服务模式）。它会在 Windows 服务中注册一个具有 System 权限的后台服务，专门负责管理 TUN 网卡。
1. 打开 Clash Verge，进入“设置”（Settings）面板。
2. 找到“Clash 内核”或“系统设置”区域，寻找 **Service Mode**。
3. 如果状态显示为未安装或红色的警告图标，请点击安装（Install）或者授权（Authorize）。
4. 此时系统会弹出 UAC 提示，点击“是”。
5. 安装成功后，右下角的地球图标（或者 Service Mode 状态指示）应变为绿色。
6. 重启 Clash Verge 客户端，再次尝试开启 TUN 模式。

如果 Service Mode 仍然无法启动，请检查系统服务（按 Win+R，输入 `services.msc`），找到名为 `Clash Core Service` 或类似的服务，确保它的启动类型被设置为“自动”，并且服务状态为“正在运行”。

## 排查步骤二：清理虚拟网卡冲突与 Wintun 驱动残留

如果您曾安装过 OpenVPN、WireGuard、v2rayN（并开启过 TUN）、Netch 或其他企业级 VPN 软件，系统中可能残留了多个 TAP/TUN 虚拟网卡设备。这些遗留驱动极易与 Clash Verge 携带的 Wintun 驱动产生冲突。

### 如何清理旧的虚拟网卡：
1. 右键点击 Windows 的“开始”按钮，选择“设备管理器”。
2. 展开“网络适配器”列表。
3. 在顶部的“查看”菜单中，勾选“显示隐藏的设备”。
4. 仔细检查列表中是否存在名称包含 `Wintun Userspace Tunnel`、`TAP-Windows Adapter` 或灰色不可用的不明网络设备。
5. 对于不需要的虚拟网卡，右键点击并选择“卸载设备”。如果弹出确认框，务必勾选“尝试删除此设备的驱动程序软件”。
6. 卸载完毕后，重新启动电脑。

此外，Clash Verge 依赖的 `wintun.dll` 文件有时可能会在软件更新过程中损坏。您可以进入 Clash Verge 的安装目录（或者配置目录 `~/.config/clash-verge/`），手动删除 `wintun.dll` 文件，然后重启软件，让它自动重新下载或释放该文件。

## 排查步骤三：TUN 开启后整机断网的 DNS 修复

有些情况下，TUN 模式确实成功开启了（开关变蓝，没有报错），但浏览器和所有软件瞬间断网，无法加载任何网页。这通常不是网络线路断了，而是 DNS 解析崩溃，导致域名无法转换为 IP 地址。如果您怀疑是节点本身不可用，请参考我们的 [机场节点连接失败排查指南](/network/airport-not-working-troubleshooting)。

### 1. 检查 Fake-IP 设置
Clash Verge 的 TUN 模式强烈依赖 `fake-ip` 机制。如果配置不当，本地 DNS 请求无法被内核正确接管。
打开您的配置文件，确保 `dns` 模块的设置类似如下：
```yaml
dns:
  enable: true
  ipv6: false
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 223.5.5.5
    - 114.114.114.114
```
如果您的配置文件中 `enhanced-mode` 被设置为了 `redir-host`，由于多数现代内核已弃用该模式，极易导致断网。请将其强制修改为 `fake-ip`。

### 2. 本地物理网卡的 DNS 被劫持或锁定
如果您的以太网或 Wi-Fi 连接被手动设置了静态且无法连通的 DNS（例如某些去广告软件残留的本地代理 IP），即使开启了 TUN 也可能受到影响。
进入 Windows 的“网络和 Internet 设置” -> “高级网络设置” -> 选择当前使用的物理网卡 -> 查看“DNS 服务器分配”。请将其设置为“自动 (DHCP)”，将解析权限完全交给 Clash 内核去处理。

## 排查步骤四：安全软件拦截与防火墙放行

国内的安全防护软件（如 360 安全卫士、腾讯电脑管家、火绒）以及系统自带的 Windows Defender，有时会将底层网络驱动的注入行为判定为恶意篡改。

- **火绒安全**：进入“系统防护”或“网络防护”日志，查看是否有关于 Clash Verge 进程或 `wintun.dll` 的拦截记录。如果有，将其加入白名单。
- **Windows Defender**：由于某些旧版本的 Clash 内核被误报，Defender 会悄悄隔离核心文件。请进入 Windows 安全中心 -> 病毒和威胁防护 -> 保护历史记录，查看是否有 `Clash.exe` 被隔离，如果有，请选择“还原并允许”。
- **卡巴斯基等杀毒软件**：部分国外严格的杀软会拦截非标准端口的加密流量。建议在设置中的“网络设置”中，排除扫描 Clash Verge 的相关进程，并信任由该软件创建的加密连接。

在排除安全软件干扰时，您可以暂时完全退出这些防护软件进行测试。如果关闭后 TUN 模式可以正常启动和联网，就明确了是拦截问题，随后再精准配置白名单即可。

## 排查步骤五：Windows 网络重置与终极修复

当您尝试了上述所有方法，TUN 模式开关仍然打不开，或者报错信息依旧时，Windows 的网络协议栈可能已经处于混乱状态。此时需要执行彻底的网络重置操作。

### 使用命令行重置网络协议
1. 点击 Windows 搜索框，输入 `cmd`，右键点击“命令提示符”，选择“以管理员身份运行”。
2. 依次输入以下三行命令，每输入一行按一次回车键：
   - `netsh winsock reset` （重置 Winsock 目录）
   - `netsh int ip reset` （重置 TCP/IP 堆栈）
   - `ipconfig /flushdns` （清除本地 DNS 缓存）
3. 命令执行完毕后，系统会提示需要重启电脑。

执行上述操作可以清除各种软件残留的网络钩子和错误的路由表条目，为 Clash Verge 创造一个干净的运行环境。重启系统后，先不要开启其他多余软件，直接以管理员权限运行 Clash Verge 并开启 TUN。如果您对代理的基础网络概念还有疑惑，可以访问我们的 [新手入门导航](/start-here) 获取更多背景知识。

## 常见问题解答 (FAQ)

### 1. 为什么点击 TUN 开关后，它瞬间又弹回关闭状态？
这是最典型的驱动创建失败表现。主要原因有三个：一是没有管理员权限；二是 Service Mode 安装失败或运行异常；三是系统存在 Wintun 驱动冲突。请严格按照本文的前两步进行排查。

### 2. 开启 TUN 模式后，微信能发消息但浏览器打不开网页是怎么回事？
微信的协议常常直接使用 IP 地址通信，不需要 DNS 解析。而浏览器高度依赖域名。这种现象 100% 是 DNS 出了问题。请检查 Clash 配置中的 `enhanced-mode` 是否为 `fake-ip`，以及默认的 `nameserver` 是否可用。

### 3. Service Mode 一直显示红色的 Uninstall 状态，点击 Install 也没反应怎么办？
这说明系统的服务注册表被锁或者有残留服务未清除。您可以打开命令行（管理员），执行 `sc delete "Clash Core Service"` 手动删除卡死的残留服务，重启电脑后再到 Clash Verge 中重新点击 Install。

### 4. TUN 模式和 System Proxy (系统代理) 能同时开启吗？
可以同时开启，但从网络原理上讲没有必要，甚至可能造成环路问题。TUN 模式已经在网卡层接管了流量，系统代理则在应用层接管。通常建议开启 TUN 时，关闭 System Proxy。

### 5. 提示 "wintun.dll is missing" 或者加载失败该去哪里下载？
不需要去第三方网站下载。只要关闭 Clash Verge，进入其安装目录或用户配置目录，删除可能残缺的 wintun.dll 文件，再次以管理员身份运行软件，它会自动从自身资源中释放全新的 dll 文件。

### 6. 使用 TUN 模式打游戏，延迟比预期的要高，怎么优化？
TUN 模式主要解决的是连通性问题（接管游戏流量），但它不能凭空降低物理链路的延迟。如果您发现延迟高，请在 Clash Verge 中为游戏服务器的 IP 段配置专用的规则，强制走直连（DIRECT）或最低延迟的专线节点。

### 7. 苹果 Mac 电脑上的 Clash Verge 也有 TUN 模式吗？排查方法一样吗？
Mac 版同样支持 TUN 模式，但其底层机制不同。Mac 不使用 Wintun 驱动，而是通过 macOS 自带的 Network Extension 框架。如果在 Mac 上打不开，通常是需要在“系统设置” -> “隐私与安全性”中允许该软件加载系统扩展。

### 8. 卸载重装 Clash Verge 能解决 TUN 模式打不开的问题吗？
单纯在控制面板卸载然后重装，往往不能解决问题，因为用户配置目录（通常位于 `C:\Users\您的用户名\.config\clash-verge`）并未被清理。如果要彻底重装解决异常，必须在卸载后手动删除该配置文件夹，再进行全新安装。
