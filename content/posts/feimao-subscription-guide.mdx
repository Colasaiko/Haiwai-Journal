当你购买了飞猫云（FeiMao Cloud）的套餐后，最关键的一步就是正确配置订阅链接。很多新手用户在面对满屏的代码和各种客户端时会感到无从下手。本文将为你提供一份极其详尽的飞猫云订阅链接使用指南，手把手教你如何获取订阅链接，并将其导入到目前最主流的三个客户端：Clash Verge（Windows/Mac）、Shadowrocket（iOS）以及 v2rayN（Windows）中。无论你是刚刚接触科学上网的小白，还是希望优化网络配置的老手，这篇教程都将帮你快速掌握飞猫云优质中转线路的配置方法，让你顺畅访问全球网络。

## 什么是飞猫云订阅链接？

在使用飞猫云服务之前，我们首先需要理解什么是“订阅链接”。简单来说，订阅链接就是一段包含飞猫云所有服务器节点信息（如节点 IP、端口、加密方式、密码等）的特殊网址。由于飞猫云采用的是高质量的**中转线路**，为了保证线路的稳定性和安全性，节点信息可能会不定期发生变动。

通过订阅链接，你的客户端（如 Clash、Shadowrocket）可以自动向飞猫云的服务器请求最新的节点列表，并将其同步到你的本地设备上。这意味着你不需要手动一个个去添加节点，只需导入一次订阅链接，后续如果节点有更新，只需在客户端中点击“更新订阅”即可获取最新配置，极大地方便了日常使用。请注意，订阅链接包含你的个人账户信息，相当于你的“通行证”，**绝对不能泄露给他人**，否则可能会导致你的账号流量被盗用甚至被封禁。

## 如何在飞猫云后台获取订阅链接？

导入节点的第一步是找到属于你自己的订阅链接。获取过程非常简单，只需按照以下步骤操作：

1. **登录飞猫云官网**：打开你的浏览器，输入飞猫云的官方网址并使用你的注册邮箱和密码登录到用户中心后台。
2. **确认套餐状态**：在用户中心的首页“仪表盘”（Dashboard）中，请先检查你的套餐是否处于“有效”状态，且剩余流量充足。如果没有可用套餐，你需要先前往商店购买。
3. **寻找“便捷导入”或“订阅中心”**：在仪表盘的显眼位置，通常会有一个区域叫做“捷径”、“便捷导入”或者直接显示各个客户端的图标。
4. **复制订阅链接**：
   - 如果你使用的是 Clash，请找到“一键导入 Clash”按钮，右键点击（或手机长按）选择“复制链接地址”。
   - 如果你使用的是 v2rayN 或其他通用客户端，请寻找“复制 V2Ray 订阅链接”或“复制通用订阅”按钮，点击复制。
   - 不要直接点击这些按钮，除非你的设备上已经安装并正确配置了相应的客户端且关联了协议。复制链接（以 `https://` 开头的一长串字符）是最保险、最通用的做法。

获取到订阅链接后，请暂时将它保存在剪贴板中，接下来我们将分别介绍在不同设备上的导入方法。如果你对客户端的选择有疑问，可以参考我们的 [如何选择优质机场](如何选择优质机场) 指南。

## 飞猫云 Clash Verge 订阅导入教程

Clash Verge 是目前 PC 端（Windows 和 macOS）最流行、界面最美观、功能最强大的 Clash 内核图形化客户端。飞猫云的中转线路在 Clash 环境下能发挥出最佳的性能和分流效果。

1. **下载并安装 Clash Verge**：确保你的电脑上已经安装了最新版的 Clash Verge。如果没有，请前往其 GitHub 发布页下载对应系统的版本进行安装。具体安装配置细节可参考 [Clash Verge 详细配置指南](clash-verge-guide)。
2. **打开订阅配置页面**：启动 Clash Verge，在左侧导航菜单中找到并点击“配置”（Profiles）或“订阅”（Subscriptions）选项。
3. **新建订阅**：在配置页面中，点击右上角的“新建”（New）按钮，或者在输入框中准备粘贴链接。
4. **粘贴飞猫云订阅链接**：将刚才在飞猫云后台复制的 Clash 订阅链接粘贴到“订阅链接”（URL）输入框中。
5. **填写名称并保存**：在“名称”（Name）一栏中输入“飞猫云”以便识别，然后点击“导入”（Import）或“保存”（Save）按钮。
6. **更新订阅**：保存后，列表中会出现“飞猫云”的配置文件。右键点击该配置文件，选择“更新”（Update），客户端会自动从飞猫云服务器拉取节点信息。此时，你通常能看到文件大小和节点数量的变化。
7. **启用配置**：**重要的一步**，单击“飞猫云”配置文件，使其左侧出现高亮或被勾选，表示已选中该配置。
8. **开启系统代理**：回到左侧菜单，点击“设置”（Settings），找到“系统代理”（System Proxy）选项并将其开启。此时，你的浏览器流量就会通过飞猫云的中转线路进行转发了。
9. **选择节点**：点击左侧的“代理”（Proxies）菜单，你可以看到飞猫云提供的所有节点。建议选择“规则”（Rule）模式，并挑选一个延迟较低的节点进行使用。

## 飞猫云 Shadowrocket (小火箭) 订阅导入教程

Shadowrocket（俗称“小火箭”）是 iOS 平台（iPhone 和 iPad）上最经典、使用最广泛的代理工具。由于其功能强大且操作相对简单，非常适合配合飞猫云的节点在移动端使用。

1. **安装 Shadowrocket**：你需要一个非中国大陆地区的 Apple ID（如美区或港区）才能在 App Store 中搜索并下载 Shadowrocket（售价通常为 2.99 美元）。安装完毕后请参考 [Shadowrocket 使用教程](shadowrocket-tutorial) 进行基础了解。
2. **添加节点**：打开 Shadowrocket 应用，在首页点击右上角的“+”号按钮。
3. **选择类型为 Subscribe**：在弹出的添加页面中，第一项“类型”（Type）默认可能是 Shadowsocks 或 Vmess，点击它，在下拉列表中滑动到底部，选择“Subscribe”（订阅）。
4. **粘贴飞猫云订阅链接**：在“URL”一栏中，粘贴你从飞猫云后台复制的订阅链接（如果是手机操作，可以先在手机浏览器登录飞猫云复制）。
5. **填写备注并保存**：在“备注”（Remarks）一栏填入“飞猫云”，然后点击右上角的“完成”（Done）或“保存”（Save）。
6. **更新获取节点**：回到 Shadowrocket 首页，你会看到“飞猫云”已经作为一个组出现在列表中。此时可能还没有节点显示，你需要向右滑动“飞猫云”这一行，点击“更新”（Update）按钮。稍等片刻，飞猫云的中转节点就会加载出来。
7. **连接测试**：点击任意一个国家/地区的节点使其前面出现小黄点，然后打开首页顶部的“未连接”开关。首次连接时，系统会提示添加 VPN 配置，允许并输入锁屏密码即可。如果右上角出现了 VPN 图标，说明连接成功。

## 飞猫云 v2rayN 电脑端导入教程

v2rayN 是 Windows 平台上另一款老牌且非常稳定的客户端，界面简洁轻量，资源占用极低，同样完美支持飞猫云的中转节点。

1. **下载安装 v2rayN**：下载最新版本的 v2rayN-Core 压缩包，解压到一个纯英文路径的文件夹中。运行文件夹内的 `v2rayN.exe` 即可启动程序。对于运行报错等问题，请查阅 [v2rayN 常见问题解决](v2rayn-troubleshooting)。
2. **设置订阅**：在 v2rayN 主界面的顶部菜单栏中，点击“订阅”（Subscription），然后选择“订阅设置”（Subscription settings）。
3. **添加订阅地址**：在弹出的“订阅设置”窗口中，点击左下角的“添加”（Add）按钮。
4. **填写信息**：
   - **备注**：输入“飞猫云”。
   - **地址（URL）**：粘贴从飞猫云后台复制的 V2Ray/通用订阅链接。
   - 填写完毕后，点击右下角的“确定”保存设置并关闭窗口。
5. **更新订阅**：回到主界面，再次点击顶部菜单的“订阅”，这次选择“更新订阅”（Update subscription）。程序底部的日志框会显示更新进度，成功后，飞猫云的节点列表就会出现在主界面的表格中。
6. **选择节点并开启路由**：
   - 选中列表中的任意一个节点，按回车键（Enter）或右键选择“设为活动服务器”。
   - 在主界面底部的“系统代理”（System proxy）下拉菜单中，选择“自动配置系统代理”（Set system proxy）。
   - 在底部的“路由”（Routing）下拉菜单中，建议选择“绕过大陆”（Bypass mainland China），这样只有访问国外网站才会消耗飞猫云的流量。

## 订阅常见问题：节点列表为空怎么办？

在配置飞猫云的过程中，最常遇到的问题就是导入订阅后，点击更新却发现“节点列表为空”或“更新失败”。遇到这种情况不要慌，通常可以从以下几个方面排查解决：

1. **检查订阅链接是否完整**：这是最常见的原因。在复制链接时，可能不小心少复制了一个字母或者多复制了空格。请回到飞猫云后台，重新仔细地完整复制一次链接。
2. **检查套餐是否过期或流量耗尽**：登录飞猫云官网，查看你的账户状态。如果套餐已经到期或者本月流量已经用完（0 GB），服务器将拒绝下发节点信息。这种情况下，你需要续费或者重置流量包。
3. **网络环境问题（被墙）**：有时候，用于获取订阅配置的域名（API 域名）本身被运营商屏蔽了。你可以尝试：
   - 切换当前设备的网络（例如从 Wi-Fi 切换到手机 4G/5G 热点）。
   - 如果你的设备上还有其他可以勉强使用的代理软件，先开启它，然后再进行更新订阅的操作（这就是常说的“搭梯子上梯子”）。
4. **客户端时间不同步**：大部分代理协议（尤其是 Vmess 和 Trojan）对系统时间要求非常严格。请确保你的电脑或手机系统时间与互联网时间（北京时间）完全一致，误差不能超过一分钟。
5. **尝试重置订阅链接**：如果你怀疑订阅链接被泄露，或者上述方法都无效，可以在飞猫云后台找到“重置订阅链接”的选项。重置后，旧的链接将立即失效，你必须使用新生成的链接重新在客户端中进行配置。

通过以上图文并茂的步骤，相信你已经成功将飞猫云的订阅链接导入到了 Clash Verge、Shadowrocket 或 v2rayN 中。飞猫云凭借其优质的中转线路，能够为你提供稳定、低延迟的国际网络访问体验。记得养成定期更新订阅的习惯，以获取最新的节点状态，确保网络始终畅通无阻。如果在实际操作中还遇到其他技术问题，可以通过官方工单系统寻求进一步的帮助。

## 常见问题解答 (FAQ)

### 1. 飞猫云的订阅链接可以分享给朋友使用吗？
绝对不可以。你的飞猫云订阅链接与你的个人账户深度绑定，包含了验证信息。如果分享给多人使用，不仅会导致你的套餐流量快速耗尽，还会触发飞猫云的安全机制，被系统判定为账号共享或恶意滥用，从而导致封号处理。请妥善保管你的链接。

### 2. 为什么我导入 Clash Verge 后无法上网？
导入并更新订阅只是获取了节点，你还需要进行两步关键操作：一是在“配置”页面选中（激活）飞猫云的配置文件；二是在“设置”中开启“系统代理”开关。此外，确保你选择了一个延迟测试正常的节点，并且飞猫云账户内仍有可用流量。

### 3. 飞猫云的中转线路和直连线路有什么区别？
飞猫云提供的高质量中转线路，意味着你的数据会先经过国内的优质服务器（入口节点），然后再通过专线或优化路由转发到国外的目标服务器。相比直连线路，中转线路在晚高峰拥堵时段表现更稳定，抗封锁能力更强，延迟更低，适合流媒体解锁和游戏加速。

### 4. 每次打开电脑/手机都需要重新导入订阅吗？
不需要。订阅链接只需在第一次配置客户端时导入一次。之后，客户端会自动保存这个链接。你只需要在日常使用中，每隔几天或遇到节点失效时，在客户端内点击“更新订阅”按钮，即可同步最新的节点列表。

### 5. Shadowrocket 更新飞猫云订阅时提示超时怎么办？
这通常是因为获取配置文件的 API 域名在当前网络下无法访问。建议先断开现有的 VPN 连接，尝试切换到手机蜂窝数据网络再次更新。如果仍然不行，可以登录飞猫云官网查看是否有关于订阅域名更换的最新公告，或者尝试重置订阅链接。

### 6. v2rayN 导入通用订阅后，节点全部显示超时 (-1)？
节点测试全部超时可能并不代表节点真坏了。首先确认 v2rayN 的核心组件是否完整，其次检查电脑系统时间是否准确。另外，v2rayN 的真连接延迟测试依赖于正确的路由设置和目标网址（默认测速网址可能被墙或被屏蔽），尝试实际在浏览器中打开 Google 等网站，如果能正常访问，就不必理会测试结果的超时提示。
